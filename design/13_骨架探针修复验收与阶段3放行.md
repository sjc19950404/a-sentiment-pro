## 4. 口径纠偏：`runSelfTest().pass` 为什么仍是 false

CodeBuddy 复验重点 1 写：「`S.runSelfTest().pass` 应从永远 false **转为 true**」，但同一段又写「`drawer.ok` 仍是阶段 4 预期项，所以完整 8 项全绿要等阶段 4」——**这两句自相矛盾**。

实测坐实（`s-selftest.js:294-300`）：

```js
report.pass =
  horizontal.count === 0 && innerScroll.violations.length === 0 &&
  (cls.pass === true || cls.pass === null) && touch.violations === 0 &&
  contrast.violations === 0 &&
  drawer.ok === true &&          // ← 仍是 false：drawer missing
  empty.missingTitle === 0 && empty.oversized === 0 &&
  skeleton.pass === true;        // ← 本轮已转 true
```

线上实测：`skeletonSwap.pass:true`、`drawerFocusTrap:{"ok":false,"steps":["drawer missing"]}`、`horizontalOverflow:0`、`cls:{value:0.0035,pass:true}` ⇒ **`report.pass:false`**。

**所以本轮正确的验收标准是 `skeletonSwap.pass === true && maxShift === 0`（已达成）**，不是 `runSelfTest().pass === true`。后者要等阶段 4 三档抽屉实现才可能转真，这与 12 册 §5.5「阶段 5 硬门槛需 8 项全绿」并不冲突——阶段 5 本来就在阶段 4 之后。请把这条复验重点的下半句当准，避免误判"探针修复没生效"而反复改探针。
