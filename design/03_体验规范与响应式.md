## 0. 令牌与前端交接契约

### 0.1 唯一令牌来源

两套方案（A / B）**共用同一套设计令牌**，来源是 BRIEF 1.B 的研究工作台 `.t-scope` 内联 CSS 与 BRIEF 1.C 的内联设计纪律注释。**不新增第三套 UI**：A 是把它升为主视图，B 是把同一套变量层反向移植回研报 DOM。

| 契约项 | 继承内容 | 禁止 |
|---|---|---|
| 设计纪律 | 「chrome 柔、数据锐」；辉光只允许三处（选中细边光 / 警报呼吸 / 主图当前值微光点）；动画只做 `opacity` / `transform`；尊重 `prefers-reduced-motion`；不用 `backdrop-filter`（树莓派掉帧）；深色磨砂黑 + 青色主色；红涨绿跌（中国 A 股约定） | 新增辉光点、新增滤镜、用 `width/height/top/left` 做动画 |
| 选择器 | 沿用 `.t-` 前缀与 `.t-scope` 作用域；12 列栅格 `t-c12 / t-c8 / t-c6 / t-c4` | 新增全局无前缀选择器污染研报视图 |
| 滚动模型 | `.t-main` 整页滚动、**零盒内滚动** | 恢复 `#preMainPanels` 恒定高 + 面板 `overflow-y:auto` |
| 组件命名 | 骨架 `sk-*`、抽屉 `dw-d1/d2/d3`、空状态 `es-t1…t6`、断点 `bp-xs/sm/md/lg`、状态 `st-loading/skeleton/ready/empty/error/stale/offline` | 与 `render*` 函数同名、改数据层导出 |

### 0.5 给前端的可编码约束

1. 所有高度由「骨架占位 → 内容原位替换」决定，**不写 `height` / `min-height` / `max-height` 锁死内容容器**；顶栏用 `min-height` 而非 `height`。
2. 展开 / 折叠用 `<details>` 或 `grid-template-rows: 0fr → 1fr`（配合 `overflow:hidden` 仅作用于折叠层内部），**不锁父容器高**。
3. 滚动容器白名单：**仅 2 个**——抽屉自身、长文专用页目录；其余一律 `overflow: visible`。
4. 动画属性白名单：`opacity`、`transform`；时长 120–200ms；`cubic-bezier(.2,.7,.3,1)`。
5. 所有固定定位元素（顶栏、ticker、悬浮按钮、底部 tab bar）必须走安全区变量（第 2.6 节）。
6. 数据层零改动：不新增请求、不改 `render*` 签名、不改写 `LINK` 事件字段。

### 2.2 XS `<640`（主战场，390px 基准）

- 视口基准 **390×844**；BRIEF 3.4 实测整页 34829px / 43 屏，目标 **≤9800px**。
- 4 列栅格仅用于结论条内部对齐与卡片内键值，外部卡片一律 1 列全宽。
- 顶栏只留「数据日 + 风险等级 + 时间窗 4 段 + ⋯」；`regime` 序列、快捷键说明、导出、研报入口全部进溢出菜单。
- 所有抽屉强制 D3 全屏 sheet；**禁止**在 390px 上出现 520px 抽屉（会横向溢出）。
- 表格一律卡片化，横向滚动元素数目标 **0**（BRIEF 3.4 的 `dt-table` 533 / right=546 必须归零）。
- 底部 tab bar + ticker 合并为一个固定容器，表单区 `padding-bottom` 让出其总高。

### 2.3 SM `640–1023`

- 平板竖屏 / 大屏手机横屏；8 列栅格，2 列卡片。
- tab 条是**全站允许横向滚动的第 1 处**（见 7.4）：仅导航条可横滚，带首尾渐隐遮罩与「→ 更多分区」文字提示；内容区禁止横滚。
- 抽屉默认 D3，用户可拖右边缘切到 D2（100vw − 48px）。
- ticker 放在内容流末尾 sticky，避免 fixed 遮挡（BRIEF 3.5「sticky 顶栏 + 左下横屏 + 右下↑ 在 9 屏逐屏重复」的整改：固定悬浮物在 <1024 全部收进底部容器）。

### 2.4 MD `1024–1439`

- 12 列栅格，3 列卡片；主图 `t-c8` + 侧栏 `t-c4`。

## 4. CLS 治理替代方案（对应 BRIEF 3.3）

### 4.1 现行方案与其代价（不得延续）

| 项 | 现行（BRIEF 3.3 实测） | 代价 |
|---|---|---|
| 基线 CLS | 桌面 **1.281** / 移动 **1.391** | — |
| 手段 | `#preMainPanels` 恒定高（桌面 22rem / 窄屏 26rem）；13 面板 + `#alerts` 锁死 `height/min/max:3rem` + `overflow-y:auto`；首屏 `.grid>.card` 锁 22rem 盒内滚；`header.topbar` 锁 64px | CLS 降到 **0.174** |
| 反噬 | 13 个平级面板压成等高条带无主次；折行**半截字裁切**；容器滚 + 面板滚 + 卡片滚 = **18 处盒内滚动容器** | 可用性损失 |
| 残余 CLS 拆解 | **0.128** 来自 `btStrategyPanel` 骨架→真实表格盒内替换；**0.046** 来自 `mom-group` | 两处共 0.174 |

**正确方向（BRIEF 3.3 明确）**：用**骨架占位（尺寸与真实内容一致）+ 内容原位替换**替代「锁死高度 + 盒内滚动」，同时解决 CLS 与裁切，**不依赖把 CLS 当硬约束**。

### 4.2 完整状态机

| 状态 | 触发 | DOM 动作 | 容器几何 | 视觉 | aria |
|---|---|---|---|---|---|
| `st-idle` | 初始 | 无 | — | — | — |
| `st-loading` | 进入 tab / 切时间窗 / 刷新 / `-` 切数据范围 / 懒挂载分区进入视口 | **同步插入骨架节点** | 锁为骨架尺寸（= 真实内容尺寸） | 顶部 2px 进度条（`transform:scaleX`）+ 骨架微光（opacity） | `aria-busy="true"` |
| `st-skeleton` | 骨架已挂载，等待数据 | 保持骨架 | **不变** | `role="status"` + 骨架条 | `aria-live="off"`（避免刷屏） |
| `st-ready` | 数据到达 | **骨架节点原位替换**（同一父节点、同一尺寸） | **不变** | `opacity 120ms` 交叉淡入 | `aria-busy="false"` |
| `st-empty` | 数据为空 / 三方未产出 / 账户空仓 | 骨架 → 空状态模板 T1–T6 | **锁为骨架高** | 空状态卡（第 8 节） | `role="status"` |
| `st-error` | 请求失败 / 超时 | 骨架 → 错误卡 + 「重试」 | **锁为骨架高** | 琥珀描边 + 可重试按钮 | `role="alert"` |
| `st-refreshing` | 已有内容时刷新 | **保留旧内容**，只加顶部进度条 | **不变** | 不回退骨架，避免闪烁 | `aria-busy="true"` |
| `st-stale` | 数据日 ≠ 今日 / 已收盘 | 结论条右侧徽章 | **不变** | 琥珀描边 + 时间戳 | `role="status"` |
| `st-offline` | `navigator.onLine === false` | 顶栏下插 40px 离线条 | 用骨架占位抵消位移 | 「离线 · 展示最近缓存」 | `role="status"` |

**转移规则**

```
idle → loading → skeleton → { ready | empty | error }
ready → refreshing → ready          (刷新不回退骨架)
任意态 → loading                     (切时间窗 / 切数据范围 / 切 tab)
skeleton → skeleton                  (懒挂载分区重新进入视口，尺寸不变)
```

**关键约束**：`skeleton → ready/empty/error` 三种终态**共用同一骨架几何**；替换只改子节点内容与 `opacity`，不改父容器的 `width` / `height` / `padding` / `margin`。

| 目标 | 机理 | 数值结果 |
|---|---|---|
| **CLS ≤0.10** | CLS 的成因是「布局位移」。骨架尺寸与真实内容 1:1 ⇒ 替换瞬间父盒几何不变 ⇒ 位移 = 0。残余 0.174 中：**0.128** 来自 `btStrategyPanel` 骨架与真实表格尺寸不一致 → 改 220px 对 220px、明细进 D3；**0.046** 来自 `mom-group` 1323px 塞进 382px 的塌陷 → 改 56px 折叠头 | 0.174 − 0.128 − 0.046 = **0**，目标 ≤0.10 留 0.10 余量 |
| **盒内滚动 18 → ≤2** | 撤掉 `#preMainPanels` 恒定高、13 面板 `3rem` 锁高 + `overflow-y:auto`、首屏 `.grid>.card` 22rem 盒内滚、`header.topbar` 64px 硬高；「容器滚 + 面板滚 + 卡片滚」三层结构消失，改回 `.t-main` 整页滚动 | 白名单只剩 **抽屉自身** 与 **长文页目录** = 2 |
| **半截字 0** | 折行被裁的根因是 `height/min/max:3rem` + `overflow-y:auto` 把两行文字压进一行；撤掉锁高后容器高度由内容决定，`min-width:0` + `word-break:keep-all` 保证整词不折 | 13 处裁切 → **0** |
| **不依赖 CLS 当硬约束** | 不再需要 22rem / 26rem 恒定容器，也不再把 18rem「不得调大或去掉」当纪律；布局高度回归内容驱动 | 骨架成为唯一占位机制 |

### 4.5 明确禁止：不得复活 BRIEF 3.3 已证伪的做法

> 以下逐条来自 BRIEF 3.3「已证伪、切勿重复建议」，实施中**全部禁止**：

| # | 禁止项 | BRIEF 实测结论 |
|---|---|---|
| 1 | ❌ 逐个给面板加 `min-height` | CLS 逐位不变 |
| 2 | ❌ 关 `scroll-behavior:smooth` / `overflow-anchor` | 无效 |
| 3 | ❌ 给 `main` 加 `contain` | 无效 |
| 4 | ❌ 给 `main` 固定高 | 无效 |
| 5 | ❌ 把 `btStrategyPanel` 放大到 26rem | 0.802 → 0.890，**反而变差** |
| 6 | ❌ 去掉高度上限 / 把 18rem「调大或去掉」 | 注释明确禁止 |
| 7 | ❌ 继续使用 `#preMainPanels` 恒定高（桌面 22rem / 窄屏 26rem）+ 面板锁 `3rem` + `overflow-y:auto` | 18 处盒内滚动与半截字的成因 |
| 8 | ❌ 首屏 `.grid>.card` 锁 22rem 盒内滚动 | 同上 |
| 9 | ❌ `header.topbar` 锁死 64px 硬高 | 改 `min-height` + 安全区内内容自适应 |
| 10 | ❌ 把 CLS 当硬约束去锁任何内容容器的高度 | 与「骨架 + 原位替换」方向相悖 |

**唯一允许的滚动容器**：抽屉自身、长文专用页目录。其余任何 `overflow-y: auto|scroll` 且 `scrollHeight > clientHeight` 的容器都算回归缺陷。

## 5. 状态设计

### 5.1 六类状态总表

| 状态 | 触发 | 视觉 | 容器行为 | 文案 / 动作 |
|---|---|---|---|---|
| **加载中** | 进 tab / 切时间窗 / `-` 切范围 / 懒挂载 | 骨架（尺寸按 4.3）+ 顶栏下方 2px 进度条（`transform:scaleX`）+ `aria-busy` | 锁骨架尺寸 | **不显示纯文字「载入中…」**（BRIEF 3.5 的失败形态） |
| **空** | 数据为空 / 三方未产出 / 账户空仓 | 空状态模板 T1–T6（第 8 节） | 收缩到模板高 120px / 108px，不占满父卡 | 主文案 + 副文案 + 1 个动作 |
| **错误（可重试）** | 请求失败 / 超时 | 琥珀描边卡 + 「重试」按钮 ≥44px | 锁骨架高 | 「数据未取到 · 重试」/「载入超时 · 重试 / 返回精简档」 |
| **陈旧数据** | 数据日 ≠ 今日 / 已收盘 | 结论条右侧「数据日 2026-11-14 · 已收盘」徽章 + 琥珀描边；**不伪装实时** | 不变 | 明确时间戳 + 「刷新」 |
| **离线** | `navigator.onLine === false` | 顶栏下 40px 离线条（骨架预占位，显示隐藏只改 `opacity`） | 骨架抵消位移 | 「离线 · 展示最近缓存（数据日 …）」 |
| **致命兜底** | 渲染异常 / 组件抛错 | **局部错误卡替换出错的单个分区**，其余 `main` 照常渲染 | 只替换该 zone，尺寸锁为该 zone 骨架高 | 「该分区暂时不可用 · 重试 / 查看其他分区」 |

### 5.2 `fatalHolder` 的克制替代

| 项 | 现状 | 替代方案 |
|---|---|---|
| 行为 | `fatalHolder` 把整个 `main` 藏掉 | **错误边界下沉到分区**：每个 zone 包一层 ErrorBoundary，出错只替换该 zone |
| 可见内容 | 全页不可用 | 顶栏、结论指标条、风险摘要条、其余 8 个 tab **照常可用** |
| 容器 | `main` 整体隐藏 → 布局塌陷 | 出错 zone 用骨架同尺寸错误卡占位，兄弟节点几何不变（CLS 0） |
| 恢复 | 需刷新整页 | 错误卡内「重试」只重挂载该 zone，不整页刷新 |
| 兜底层级 | 单点 | 三级：分区 ErrorBoundary → tab 面板 ErrorBoundary → 顶栏内「部分数据不可用」全局提示条（**始终不隐藏 main**） |
| aria | — | `role="alert"` + `aria-live="assertive"`，但只播报出错分区名 |

### 5.3 「载入完整档」卡住的正确反馈设计

> 现状（BRIEF 3.5）：点击后变「载入中…」，**6 秒后仍如此**，行数与高度不变，既不完成也不报错。

| 时间 | 状态 | 按钮 / 界面 | 高度与行数 |
|---|---|---|---|
| 0–300ms | `st-loading` | 按钮 `disabled` + 内联 spinner（仅 `transform:rotate`）+ 文案「载入中 0/265 日」 | 骨架占位，尺寸不变 |
| 300ms–10s | `st-loading` 分段 | 顶部进度条 `scaleX` + 分段计数「已载入 120/265 日」，每批到达时**骨架逐批原位替换** | 行数按批次增长，每批用同尺寸骨架 |
| 完成 | `st-ready` | toast「完整档已载入 265 日」+ `aria-live="polite"` 播报 + 刷新反馈可见化（5.4） | 尺寸 = 骨架尺寸 |
| **>10s 硬超时** | `st-error` | 「完整档载入超时 · 重试 / 返回精简档」，按钮**恢复可点** | 锁错误卡高 |
| 离线 | `st-offline` | 「离线 · 已保留 30 日精简档」 | 不变 |

**硬约束**：任何时刻按钮都**不得**处于不可解释的静默 pending；状态必须是 `完成 / 错误 / 可重试 / 分段进度` 四者之一。`-` 键与按钮共用此状态机，语义标注为「30 日精简档 ↔ 265 日完整档的**数据范围**切换」。

### 5.4 刷新反馈可见化

> 现状（BRIEF 3.5）：DOM 文字更新但视觉几乎看不到；BRIEF 3.6 的「刷新回『已是最新』」资产保留。

| 通道 | 规则 |
|---|---|

| 读屏 | `aria-live="polite"` 容器播报「数据已刷新，数据日 2026-11-14」 |
| 无变化 | 明确播报「已是最新，无新增数据」，不做静默无反馈 |
| 禁止 | 整页重载、整屏闪烁、新增辉光点 |

### 5.5 其余弱反馈补齐

- 表头背景用不透明 `--surface`，禁止 `backdrop-filter`（BRIEF 1.C）。
- 表格行高 36px；可点击行 44px + `tabindex="0"` + `role="button"` + `aria-haspopup="dialog"`。

### 7.4 横向滚动的明确边界（何时允许、如何提示）

> **全站只允许 2 处横向滚动**，其余横向溢出元素数必须为 **0**（BRIEF 3.4 的 `dt-table` 533 / right=546、导航 479 都不在白名单内）。

| ② D2/D3 抽屉内的**超宽矩阵**（如 12 个月份列） | 仅在抽屉内，且列数 > 8 | 抽屉顶部「← 横向滑动查看 N 列 →」文字提示 + 右边缘渐隐遮罩 | P0 列 `position:sticky; left:0` 常显；抽屉外不出现横滚 |

**其他一律禁止**：`zone-backtest` 大表、`dt-table`、`verTable`、四张空表、研报长文表格在 <1024 必须走「主列 + 次列折叠」或卡片化，不靠横向滚动兜底。

## 9. 动效与可访问性

### 9.1 动效

| 项 | 规则 |
|---|---|
| 属性白名单 | 只做 `opacity` / `transform`（BRIEF 1.C）；禁止 `width` / `height` / `top` / `left` 动画 |
| 时长 / 曲线 | 120–200ms；`cubic-bezier(.2,.7,.3,1)`；骨架微光 1.2s 循环仅 `opacity` |
| 辉光 | 只允许三处：选中细边光、警报呼吸、主图当前值微光点；不新增 |
| 状态切换 | 骨架 → 内容 `opacity 120ms`；刷新脉冲 200ms；抽屉推入 `transform:translateX/Y 180ms`；toast 淡入淡出 160ms |
| 禁止 | `backdrop-filter`（树莓派掉帧）、视差、整屏闪烁、无限循环装饰动画 |
| `prefers-reduced-motion: reduce` | **全部动效降为 0ms**；骨架微光停止改静态灰条；进度条改静态文字计数「已载入 120/265 日」；抽屉直接出现/消失不做位移；平滑滚动改瞬间跳转；警报呼吸改静态琥珀描边 |

### 9.2 焦点

| 项 | 规则 |
|---|---|
| 可见焦点环 | `outline: 2px solid var(--focus); outline-offset: 2px`；所有可交互元素必须有可见焦点 |
| 顺序 | `Tab` 顺序 = DOM 顺序 = 视觉顺序；结论指标条 → 风险摘要条 → 走势图 → 证据卡 → 操作入口 → ticker |
| Skip link | 首个元素「跳到主内容」，聚焦时可见，`#main` 为目标 |
| 抽屉 | focus trap + `return focus`（第 6.1 节）；背景 `inert` |
| 分区锚点 | 跳转后焦点到分区标题（`tabindex="-1"`） |
| 表格行 | `tabindex="0"` + `role="button"`，`Enter` / `Space` 打开抽屉 |
| 禁止 | `outline:none` 无替代；用 `div` 冒充按钮 |

### 9.3 对比度

| 项 | 目标 | 测量 |
|---|---|---|
| 正文（Body / Table / Caption） | **≥4.5:1** | axe-core / Lighthouse a11y |
| 大字（D0 / H1 / H2）与图形边界 | **≥3:1** | 同上 |
| `--text-2` 对 `--bg` | 6.49:1 | 色板已核算 |
| `--up` / `--down` 对 `--bg` | 6.32:1 / 8.32:1 | 红涨绿跌不用纯 `#f00` / `#0f0` |
| 禁用态 | 允许降至 3:1，但必须同时有 `aria-disabled` 与文字说明 | 同上 |

### 9.4 色盲冗余

| 场景 | 冗余手段 |
|---|---|
| 红涨绿跌 | 除颜色外必须带 **▲ / ▼ 箭头**或 **+ / − 符号**或「涨 / 跌」文字；不单独靠色相区分 |
| 红绿占比条 | 除颜色外带**文字标签 + 数值**，并加不同纹理（斜线 / 点阵）；抽屉 `#drawer` 现有占比条按此补齐 |
| 风险等级徽章 | 「高 / 中 / 低」文字 + 图形形状（实心圆 / 半圆 / 空心圆）+ 颜色三重编码 |
| 陈旧数据 / 告警 | 琥珀描边 + 图标 + 文字，不靠颜色 |
| 图形验证 | 用色盲模拟（红绿色盲 / 全色盲）截图检查，所有状态仍可区分 |

### 9.5 键盘路径（完整清单）

| 键 | 行为 |
|---|---|
| `Tab` / `Shift+Tab` | 按 DOM 顺序前进 / 后退；抽屉内循环 |
| `1`–`6` | 跳分区（保留 BRIEF 3.6 行为，映射见 1.3） |
| `/` | 聚焦搜索（输入框 / 抽屉内不劫持） |
| `-` | 30 日精简档 ↔ 265 日完整档的**数据范围**切换 |
| `Enter` / `Space` | 激活按钮、表格行、折叠头、tab |
| `Esc` | 抽屉 > 菜单 > tooltip 依次关闭 |
| 方向键 | tablist 内移动焦点；表格行移动焦点；横向滚动白名单内滚动导航条 |
| `Home` / `End` | tablist 首尾 |

### 9.6 ARIA 清单

| 组件 | ARIA |
|---|---|
| tab 导航 | `role="tablist"` / `role="tab"` + `aria-selected` + `aria-controls` / `role="tabpanel"` + `aria-labelledby` |
| 抽屉 D1/D2/D3 | `role="dialog"` + `aria-modal="true"` + `aria-labelledby`（标题）+ 背景 `inert` |
| 溢出菜单 | `role="menu"` / `role="menuitem"` + `aria-expanded` + `aria-haspopup` |
| 骨架 | `role="status"` + `aria-busy="true"` 在父容器；骨架本身 `aria-hidden="true"` |
| 加载进度 | `role="progressbar"` + `aria-valuenow` / `aria-valuemin` / `aria-valuemax`（如「已载入 120/265 日」） |
| 刷新 / 完成播报 | 独立 `aria-live="polite"` 容器；错误用 `role="alert"` |

| 风险等级 | 文字标签 + `aria-label="风险等级：高"` |
| ticker | `aria-live="off"`（避免持续播报行情数字） |

## 10. 高风险交互与降级方案

| 编号 | 高风险交互 | 主方案 | 降级方案 |
|---|---|---|---|
| R1 | 主视图切换与深链语义反转（文件 01 第 5.4 节） | 特性开关 + 深链幂等映射 + 双视图并存 2 个发版周期 | 开关回 B：`?view=report` 强制研报主视图，`?view=terminal` 语义自动复原；回滚 ≤15 分钟 |

| R10 | 局部错误边界不生效 | 分区 ErrorBoundary 替换单 zone | 三级兜底：分区 → tab 面板 → 顶栏提示条；**任何一级都不隐藏整个 `main`**（替代 `fatalHolder`） |
