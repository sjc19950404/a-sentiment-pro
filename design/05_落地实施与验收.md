## 0. 边界与三条实现机制

### 0.1 「不改 app.js 的数据逻辑」如何做到

| 机制 | 做法 | 为什么不动数据层 |
|---|---|---|
| **A. 新增适配层（DOM 搬迁）** | 新增 `s-adapter.js`，用 `MutationObserver` 观察既有 render 的产出节点，或订阅既有 `LINK` 总线；节点用 `appendChild` / `replaceChildren` **移动**到 `.s-*` 容器。移动节点不触发重新计算、不读 JSON、不调用 render | 既有函数照常写入旧容器，适配层在其之后把节点搬走，函数体与取值口径完全不变 |
| **B. CSS 覆盖层（作用域隔离）** | 新增 `s-bridge.css`，所有选择器以 `.s-scope` 开头；只在 `.s-scope` 内复位 `header / main / table / details` 等裸标签样式。绝不写全局 `*`、绝不写 `#oldId`、绝不写全局 `!important` | `style.css` 141KB 的裸标签选择器继续只作用于研报视图，两套样式互不可见 |
| **C. 渐进增强（包装而非改写）** | 若必须知道「某 render 何时完成」，只在运行时包装：`var _o = window.renderX; window.renderX = function(){ var r = _o.apply(this, arguments); S.afterX(); return r; };` | 不改 `app.js` 文件一个字节；包装层在独立文件中，`_o` 原样调用，参数与返回值不变 |

补充约束：

- 适配层**不重新实现**任何指标计算、不新增 `fetch`、不改写 `data/*.json` 的解析；
- 新层所有 id 使用 `s*` 前缀（`sKpiScore`、`sDrawerBody` 等），**不复用**任何旧 id，避免 id 选择器命中；
- 所有写操作（保存并写盘、重置账户、一键空仓、提交委托、批量提交、按实时价结算挂单）保持原 id 与原事件绑定，适配层不监听、不拦截、不重放；
- 每个阶段挂一个独立 feature flag，回滚 = 关 flag，无需发版、无需回滚数据。

### 0.2 feature flag 契约

```js
(function (S) {
  "use strict";
  var params = new URLSearchParams(location.search);
  var stored = {};
  try { stored = JSON.parse(localStorage.getItem("sFlags") || "{}"); } catch (e) { stored = {}; }

  S.flags = {
    mount:      read("mount", false),
    overview:   read("overview", false),
    tableV2:    read("tableV2", false),
    drawerV2:   read("drawerV2", false),
    reportV2:   read("reportV2", false),
    defaultWorkbench: read("defaultWorkbench", false)
  };

  function read(key, fallback) {
    if (params.has("sflag-" + key)) { return params.get("sflag-" + key) === "1"; }
    if (Object.prototype.hasOwnProperty.call(stored, key)) { return Boolean(stored[key]); }
    return fallback;
  }

  S.setFlag = function setFlag(key, value) {
    S.flags[key] = Boolean(value);
    try {
      localStorage.setItem("sFlags", JSON.stringify(S.flags));
    } catch (e) { /* storage disabled: flag applies to this page load only */ }
  };
}(window.S = window.S || {}));
```

回滚示例：`?sflag-defaultWorkbench=0` 立即回到研报视图；或在控制台执行 `S.setFlag('defaultWorkbench', false); location.reload();`。

## 2. 与现有 `.t-*` / `.t-scope` / `#tRoot` / `style.css` 的共存策略

### 2.1 三套样式的作用域边界

| 层 | 根 / 前缀 | 体量 | 阶段 1 至 4 状态 | 阶段 5 状态 |
|---|---|---|---|---|
| 研报视图 | 裸标签 + 裸 class（`.card`、`.topbar`、`header`）+ `style.css` 141KB | 141KB | 保留，默认主视图 | 精简为打印基础子集，原文件另存 `style.legacy.css` 保留 |
| 终端视图 | `#tRoot.t-scope`，全部 `.t-` 前缀，内联 CSS（index.html 第 40 至 723 行） | 40KB | 保留，`?view=terminal` 可打开 | 下线内联 CSS 与 fixed 入口；深链重定向到工作台对应 tab |

### 2.2 避免选择器打架的具体规则

1. **基础重置限定作用域**：`tokens.css` 的 `box-sizing`、`[hidden]`、`:focus-visible`、滚动条样式全部写成 `.s-scope, .s-scope *, .s-scope *::before, .s-scope *::after` 这组受限选择器，绝不出现裸 `*` 或 `html, body {}` 重置。
2. **类名不复用裸名**：新层只用 `s-` 前缀类名；不出现 `.card` / `.topbar` / `.grid` / `.drawer` 等 `style.css` 已在用的裸 class。
3. **裸标签复位用 `s-bridge.css`**：`style.css` 的 `header {}` / `main {}` / `table {}` / `details {}` 类型选择器会穿透进 `.s-scope`。桥接层只在该作用域内复位：

4. **id 不碰撞**：新层 id 一律 `s*` 前缀；`s-bridge.css` 不出现任何旧 id 选择器；适配层用 `getElementById` 读旧节点但不改其样式。
5. **z-index 分层**：`.s-*` 使用 `--s-z-sticky: 100` / `--s-z-ticker: 110` / `--s-z-drawer-mask: 900` / `--s-z-drawer: 910` / `--s-z-tooltip: 950`。
   > **评审修订（入口按钮隔离）**：终端 fixed 入口「⚡ 图表终端」在**线上真实代码中没有 `.t-entry` 这个 class**（`.t-entry` 在 `index.html` 出现 0 次）。真实写法是 `const entry = el('button', '', '⚡ 图表终端')`（第二个参数 className 为空串）、`entry.style.cssText = 'position:fixed;top:8px;right:12px;z-index:9998;...'`、`document.body.appendChild(entry)`——**无 id、无 class、无 `data-*`，样式全内联**。因此原先示意的一条 `.s-scope ~ .t-entry { display:none }` **永不匹配**（类名不存在，且 `~` 还要求 `.t-entry` 是 `.s-scope` 的后续同级兄弟，而按钮挂在 `body` 末尾）；`z-index: 9998` 又高于抽屉 910 / tooltip 950，不处理会一直盖在工作台浮层之上。
   >
   > **正确做法**：阶段 1 改 `terminal.js` **源文件**（不是内联生成物）补稳定锚点 `entry.id = 't-entry'` 后重新生成内联块；由 `s-flags.js` 在 `body` 上打 `[data-view="workbench"]`，隐藏规则写 `body[data-view="workbench"] #t-entry { display: none }`，**不要用兄弟选择器**。阶段 5 直接移除按钮。验收断言：`body > button` 中文本含「图表终端」的元素在工作台态 `display === 'none'`、研报态仍可见可点。注意该按钮 `position:fixed` ⇒ `offsetParent === null`，可见性断言**不得**用 `offsetParent !== null` 过滤，否则漏检。
6. **打印样式隔离**：`report.html` 只引入 `tokens.css` + `components.css`，不引入 `style.css`，因此两套 `@media print` 不会叠加。`components.css` 的打印规则只作用于 `.s-scope` 内。
7. **LINK 总线只读订阅**：适配层调用既有 `LINK` 的订阅接口取事件，不替换总线对象、不改事件名；工作台自己的抽屉与研报 `#drawer` 在阶段 1 至 4 各管各的，阶段 4 后统一收敛到 `.s-drawer`。

## 5. 验收清单与可执行测试代码

### 5.1 自动化自检脚本（浏览器控制台 / CDP Runtime.evaluate 通用）

把以下脚本另存为 `s-selftest.js`，在浏览器控制台直接粘贴运行，或在 CDP 里作为 `Runtime.evaluate` 的 `expression` 执行（`awaitPromise: true`、`returnByValue: true`）。脚本无外部依赖、无副作用（测试节点用 `contain: layout` 隔离并在结束时移除），返回一份 JSON 报告。

```js
(function (S) {
  "use strict";

  function wait(ms) {
    return new Promise(function (resolve) { setTimeout(resolve, ms); });
  }

  function rgb(str) {
    var m = String(str || "").match(/rgba?\(([^)]+)\)/);
    if (!m) { return null; }
    var p = m[1].split(",").map(function (x) { return parseFloat(x); });
    return { r: p[0], g: p[1], b: p[2], a: p.length > 3 ? p[3] : 1 };
  }

  function lum(c) {
    function f(v) {
      v = v / 255;
      return v <= 0.03928 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4);
    }
    return 0.2126 * f(c.r) + 0.7152 * f(c.g) + 0.0722 * f(c.b);
  }

  function opaqueBg(el) {
    var node = el;
    while (node && node !== document.documentElement) {
      var c = rgb(getComputedStyle(node).backgroundColor);
      if (c && c.a >= 0.99) { return c; }
      node = node.parentElement;
    }
    return rgb(getComputedStyle(document.documentElement).backgroundColor) || { r: 11, g: 14, b: 17, a: 1 };
  }

  function ratio(fg, bg) {
    var a = lum(fg);
    var b = lum(bg);
    return (Math.max(a, b) + 0.05) / (Math.min(a, b) + 0.05);
  }

  function visible(el) {
    var r = el.getBoundingClientRect();
    var s = getComputedStyle(el);
    return r.width > 0 && r.height > 0 && s.visibility !== "hidden" && s.display !== "none";
  }

  function path(el) {
    var out = [];
    var n = el;
    while (n && n.nodeType === 1 && out.length < 4) {
      out.unshift(n.tagName.toLowerCase() + (n.id ? "#" + n.id : "") + (n.className && typeof n.className === "string" ? "." + n.className.trim().split(/\s+/).slice(0, 2).join(".") : ""));
      n = n.parentElement;
    }
    return out.join(" > ");
  }

  function checkHorizontalOverflow() {
    var vw = document.documentElement.clientWidth;
    var bad = [];
    Array.prototype.forEach.call(document.querySelectorAll(".s-scope *"), function (el) {
      if (!visible(el)) { return; }
      var r = el.getBoundingClientRect();
      var ox = getComputedStyle(el).overflowX;
      var selfOverflow = el.scrollWidth > el.clientWidth + 1 && (ox === "visible" || ox === "auto" || ox === "scroll");
      if (r.right > vw + 1 || selfOverflow) {
        bad.push({ path: path(el), right: Math.round(r.right), vw: vw, scrollW: el.scrollWidth, clientW: el.clientWidth, overflowX: ox });
      }
    });
    return { count: bad.length, items: bad.slice(0, 20) };
  }

  function checkInnerScroll() {
    var allow = function (el) {
      return el.classList.contains("s-drawer__body") ||
        (el.classList.contains("s-table__viewport") && el.getAttribute("data-mode") === "virtual");
    };
    var all = [];
    Array.prototype.forEach.call(document.querySelectorAll(".s-scope *"), function (el) {
      if (!visible(el)) { return; }
      var oy = getComputedStyle(el).overflowY;
      if ((oy === "auto" || oy === "scroll") && el.scrollHeight > el.clientHeight + 2) {
        all.push({ path: path(el), overflowY: oy, scrollH: el.scrollHeight, clientH: el.clientHeight, whitelisted: allow(el) });
      }
    });
    var violations = all.filter(function (x) { return !x.whitelisted; });
    return { count: all.length, whitelisted: all.length - violations.length, violations: violations.slice(0, 20) };
  }

  function collectCls() {
    return new Promise(function (resolve) {
      var sessions = {};
      var seen = {};
      var observer = null;
      function add(entry) {
        if (entry.hadRecentInput) { return; }
        var key = entry.startTime + ":" + (entry.sources || []).length;
        if (seen[key]) { return; }
        seen[key] = 1;
        var sid = entry.sessionId || "s0";
        if (!sessions[sid]) { sessions[sid] = { value: 0, last: 0, start: entry.startTime }; }
        var s = sessions[sid];
        if (entry.startTime - s.last > 1000 || entry.startTime - s.start > 5000) {
          s.value = 0;
        }
        s.value += entry.value;
        s.last = entry.startTime;
      }
      try {
        observer = new PerformanceObserver(function (list) {
          list.getEntries().forEach(add);
        });
        observer.observe({ type: "layout-shift", buffered: true });
      } catch (e) {
        resolve({ value: null, note: "layout-shift unsupported", target: 0.10, baseline: 0.174, pass: null, degraded: null });
        return;
      }
      setTimeout(function () {
        if (observer) { observer.disconnect(); }
        var max = 0;
        Object.keys(sessions).forEach(function (k) { max = Math.max(max, sessions[k].value); });
        resolve({
          value: Number(max.toFixed(4)),
          sessions: Object.keys(sessions).length,
          target: 0.10,
          baseline: 0.174,
          pass: max <= 0.10,
          degraded: max > 0.174
        });
      }, 5000);
    });
  }

  function checkTouchTargets() {
    var sel = "button, a[href], input, select, textarea, summary, [role='tab'], [role='button'], [tabindex='0']";
    var bad = [];
    var checked = 0;
    Array.prototype.forEach.call(document.querySelectorAll(".s-scope " + sel), function (el) {
      if (!visible(el)) { return; }
      if (el.closest(".s-prose__toc")) { return; }
      checked += 1;
      var r = el.getBoundingClientRect();
      if (r.width < 44 || r.height < 44) {
        bad.push({ path: path(el), w: Math.round(r.width), h: Math.round(r.height) });
      }
    });
    return { checked: checked, min: 44, violations: bad.length, items: bad.slice(0, 20) };
  }

  function checkContrast() {
    var sel = ".s-kpi__label, .s-kpi__value, .s-card__title, .s-section__title, .s-verdict__text, .s-btn, .s-table th, .s-table td, .s-ticker__item, .s-prose p, .s-badge";
    var bad = [];
    var checked = 0;
    var minRatio = 99;
    Array.prototype.forEach.call(document.querySelectorAll(".s-scope " + sel), function (el) {
      if (!visible(el)) { return; }
      var fg = rgb(getComputedStyle(el).color);
      if (!fg) { return; }
      var bg = opaqueBg(el);
      var r = ratio(fg, bg);
      var size = parseFloat(getComputedStyle(el).fontSize);
      var need = size >= 24 ? 3 : 4.5;
      checked += 1;
      minRatio = Math.min(minRatio, r);
      if (r < need) {
        bad.push({ path: path(el), ratio: Number(r.toFixed(2)), need: need, color: getComputedStyle(el).color });
      }
    });
    return { checked: checked, minRatio: Number(minRatio.toFixed(2)), violations: bad.length, items: bad.slice(0, 20) };
  }

  async function checkDrawerFocusTrap() {
    var out = { ok: false, steps: [] };
    var drawer = document.getElementById("sDrawer");
    var mask = document.getElementById("sDrawerMask");
    if (!drawer || !mask) {
      out.steps.push("drawer missing");
      return out;
    }
    if (!S || typeof S.openDrawer !== "function") {
      out.steps.push("S.openDrawer missing: static aria check only");
      out.ok = drawer.getAttribute("aria-modal") === "true" && drawer.getAttribute("role") === "dialog";
      return out;
    }
    var before = document.activeElement;
    S.openDrawer({
      title: "自检", sub: "自检", size: "md",
      render: function (body) { body.textContent = "自检内容"; }
    });
    await wait(80);
    out.steps.push("hidden after open = " + drawer.hidden);
    out.steps.push("aria-modal = " + drawer.getAttribute("aria-modal"));
    out.steps.push("focus inside = " + drawer.contains(document.activeElement));
    document.dispatchEvent(new KeyboardEvent("keydown", { key: "Escape", bubbles: true }));
    await wait(280);
    out.steps.push("closed by ESC = " + drawer.hidden);

  function checkEmptyStates() {
    var list = [];
    Array.prototype.forEach.call(document.querySelectorAll(".s-scope .s-empty"), function (el) {
      if (!visible(el)) { return; }

        hasHint: !!el.querySelector(".s-empty__hint"),

      missingTitle: list.filter(function (x) { return !x.hasTitle; }).length,
      oversized: list.filter(function (x) { return x.oversized; }).length,
      items: list.slice(0, 20)
    };
  }

    wrap.appendChild(anchor);

    var t1 = anchor.getBoundingClientRect().top;
    var realH = real.getBoundingClientRect().height;

    var d2 = 0;                                        // 原子替换无第二帧

      skeletonH: Math.round(skelH), realH: Math.round(realH),
      duringInsert: Number(d1.toFixed(2)), afterReplace: Number(d2.toFixed(2)),

      pass: Math.max(d1, d2) < 1 && Math.abs(skelH - realH) < 1
```

**8 项检测与阈值**：

| 检测 | 函数 | 通过阈值 |
|---|---|---|
| 横向溢出元素数 | `checkHorizontalOverflow` | `count === 0` |
| 盒内滚动容器数 | `checkInnerScroll` | `violations.length === 0`（白名单：`s-drawer__body`、虚拟滚动时的 `s-table__viewport`） |
| CLS | `collectCls` | `PerformanceObserver` session 值 `<= 0.10` |
| 触控目标尺寸 | `checkTouchTargets` | 全部 >= 44x44 |
| 对比度 | `checkContrast` | 正文 >= 4.5、大字 >= 3.0 |
| 抽屉焦点陷阱 | `checkDrawerFocusTrap` | 打开后焦点在抽屉内、ESC 关闭、焦点归还 |
| 空状态 | `checkEmptyStates` | 有 `__title`、高度 <= 320px |
| 骨架到内容替换位移 | `checkSkeletonSwap` | `maxShift < 1px` 且骨架与真实高度差 < 1px |

> **CLS 判定口径（评审修订，务必按此实现）**：`collectCls()` 采用**双档**——`target: 0.10` 是唯一放行依据（`pass: max <= 0.10`），`baseline: 0.174` 是现行锁高方案的实测值，只用于标记 `degraded: max > 0.174`（比现状还差，直接 P1 阻断）。**不得把 `baseline` 当放行阈值**：那会放行 0.15 的版本，而 01/03 册与阶段 2 上线条件要求的是 ≤0.10。灰度期允许出现 `pass: false` 且 `degraded: false`（优于现状但未达标），但阶段 5 翻默认视图前必须 `pass: true`。
>
> **观测窗口 5 秒**：`setTimeout` 必须为 `5000`，与 4.3 节及文件 03 验收表「加载后 5s 窗口」一致。34 个 `data/*.json` 分批异步到达，若只观测 1.8 秒就会漏掉后到的位移，系统性低估 CLS。`layout-shift` 不受支持时返回 `pass: null`，按「未测」处理，**不得当作通过**。

> **采样次数（评审补充，见 07 册 §7.4）**：单次采样噪声大——同页面同视口两次实跑 **0.112 → 0.1593**（波动约 42%）。CLS 验收须**每档 ≥3 次采样**（同页面同视口），取**中位数**且**最差值 ≤0.10** 才算通过；单次采样不得作为阶段 5 硬门槛依据。
>
> **本节脚本是阶段 0 待实现的新增文件**（`s-selftest.js`），不是仓库现成工具；`S.runSelfTest()` / `collectCls()` 需随阶段 0 一起落地后才能被调用。仓库现有的 `npm run lh` 与 `.lighthouse/baseline.json` 是 Lighthouse 侧复核，不替代本节 CDP 自检。（本文件**不自动调用** `S.runSelfTest()`，阶段 0 下零副作用；由 5.2 的 CDP 脚本或控制台显式 `S.runSelfTest()` 触发。）

```js
// s-selftest.cdp.cjs

const http = require("http");
const fs = require("fs");

function getJSON(url) {
  return new Promise(function (resolve, reject) {
    http.get(url, function (res) {
      let data = "";
      res.on("data", function (c) { data += c; });
      res.on("end", function () {
        try { resolve(JSON.parse(data)); } catch (e) { reject(e); }
      });
    }).on("error", reject);
  });
}

async function main() {
  const targetUrl = process.argv[2] || "https://sjc19950404.github.io/a-sentiment-pro/?view=workbench";
  const list = await getJSON("http://127.0.0.1:9222/json/list");
  const page = list.find(function (x) { return x.type === "page"; });
  if (!page) { throw new Error("no page target on port 9222"); }

  const WS = globalThis.WebSocket || require("ws");
  const ws = new WS(page.webSocketDebuggerUrl);
  let id = 0;
  const pending = new Map();

  ws.onmessage = function (ev) {
    const msg = JSON.parse(ev.data);
    if (msg.id && pending.has(msg.id)) {
      const p = pending.get(msg.id);
      pending.delete(msg.id);
      msg.error ? p.reject(new Error(JSON.stringify(msg.error))) : p.resolve(msg.result);
    }
  };

  function send(method, params) {
    return new Promise(function (resolve, reject) {
      const n = ++id;
      pending.set(n, { resolve, reject });
      ws.send(JSON.stringify({ id: n, method, params: params || {} }));
    });
  }

  await new Promise(function (resolve, reject) {
    ws.onopen = resolve;
    ws.onerror = reject;
  });

  await send("Page.enable");
  await send("Runtime.enable");
  await send("Page.navigate", { url: targetUrl });
  await new Promise(function (r) { setTimeout(r, 4000); });

  const expression = fs.readFileSync("./s-selftest.js", "utf8");
  const result = await send("Runtime.evaluate", {
    expression: expression,
    awaitPromise: true,
    returnByValue: true,
    userGesture: true
  });

  if (result.exceptionDetails) {
    console.error("EVALUATE ERROR", JSON.stringify(result.exceptionDetails));
    process.exitCode = 1;
  } else {
    const report = result.result.value;
    console.log(JSON.stringify(report, null, 2));
    process.exitCode = report && report.pass ? 0 : 1;
  }
  ws.close();
}

main().catch(function (e) {
  console.error(e);
  process.exitCode = 1;
```
