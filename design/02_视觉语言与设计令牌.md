## 1. 设计定位与三条不可违背的原则

**定位**：面向盘后复盘与风险识别的**分析辅助工具**，不是下单终端，也不是审计报告阅读器。视觉目标是把「今天盘面有什么风险」在首屏第一眼回答完，其余内容按证据链逐层展开。

### 原则一 · 分析辅助工具 ≠ 交易终端（屏幕预算硬约束）

BRIEF 3.2 实测：模拟盘 36% + 回测 22% = **58% 屏幕给操作/审计**，而回答风险的告警 + 概览只有 **17%**。本方案把首屏（桌面 900px 可视高度内、移动 780px 内）的纵向预算锁死为：

| 层级 | 首屏预算 | 承载内容 | 超出部分的处理 |
|---|---|---|---|
| 结论层 | **≥ 45%** | 唯一大字结论、6 个核心指标、分级告警、60 日情绪分主图 | 不折叠 |
| 证据层 | **≈ 35%** | 七因子仪表、regime 分布、主线题材、涨跌家数明细 | 折入 `<details>`，保留已有折叠资产 |
| 操作层 | **≤ 20%** | 模拟盘、回测明细、参数滑块、导出入口 | 默认收起，入口置于证据层之后 |

**禁止**：把回测表格、模拟盘账户、参数滑块放在首屏前 45%；禁止用「等宽等距等密度的深色条块」平铺 14 类功能（BRIEF 3.1 根因）。

### 原则二 · 结论优先（唯一焦点、分级告警）

- 全站**只能有一个 `display` 级大字**（56px / 桌面，40px / 移动），内容是 `38.4` 情绪分或其对应的核心结论，位置必须在首屏第 1 屏内、垂直位置 ≤ 220px。BRIEF 3.2 记录现状「全站唯一大字 38.4 出现在第 459px，前面被 13 条平级告警堵着」——本次把它前移并清空其上方争抢物。
- 13 条状态/告警**必须分 3 级**，禁止 13 个平级等高条带：`critical`（琥珀呼吸，见辉光落点 ②）/ `warn`（静态琥珀描边）/ `info`（中性，可折叠为一行摘要）。默认只展开 `critical` + `warn`，`info` 收进一行。
- 沿用工作台已验证的「结论层 → 证据层」组织顺序（6 指标 → 60 日情绪分大图 → 七因子环形仪表 → regime 分布 → 主线题材 → ETF 对冲卡）。

**禁止**：出现第二个 56px 数字；禁止 13 条告警等高、同色、同字重并列；禁止用颜色深浅代替「结论 / 证据 / 操作」的层级差（须用字级 + 表面层级 + 纵向位置三重区分）。

### 原则三 · chrome 柔 / 数据锐（可量化边界）

| 对象 | 对比度约束 | 允许手段 | 禁止手段 |
|---|---|---|---|
| **chrome**（表面、边框、导航、分割线） | 边框对其所在表面 **1.09–1.81:1**，刻意低对比 | 1px 实线、明度微差（相邻级 ≈1.12:1）、`--s-shadow-1/2/3` | 彩色描边、发光、渐变、`backdrop-filter`、悬浮位移 |
| **数据**（数值、曲线、涨跌幅、坐标） | 文本 **≥ 4.5:1**，图形/UI 边界 **≥ 3:1** | 高对比文本、等宽 `tabular-nums`、2px 实线、语义色 | 低对比灰字承载数值、细于 1.5px 的数据线、用字重代替颜色传涨跌 |
| **辉光** | 全站**仅 3 处**（见 §2.6） | 见 §2.6 表 | 其余任何按钮 / 卡片 / 标题 / 图标发光 |

**禁止**：给数据区加磨砂/模糊；给 chrome 加高对比彩色；任何位置使用 `backdrop-filter` 或 `filter: blur()`（BRIEF 明确记录树莓派掉帧）。

## 2. 完整色彩系统

色相基准：表面统一 **H210 冷灰蓝**（磨砂黑，非纯黑）、低饱和 S19–27%；主色 **H186 青**；市场语义 **H360 红 / H158 绿**。下表 HSL 与对比度均由色值实算得出，非估值。

### 2.1 表面层级（深色，5 级明度 + 1 下沉级 + 状态覆盖）

| 令牌 | HEX | HSL | 用途 | 相对背景/前级对比度 |
|---|---|---|---|---|
| `--s-bg-0` | `#0B0F13` | H210 S27% L6% | 页面画布最底 | 基准 |
| `--s-bg-1` | `#10151A` | H210 S24% L8% | 分区底、ticker 底 | 对 bg-0 1.12:1 |
| `--s-surface-1` | `#161C22` | H210 S21% L11% | 卡片、图表容器、表格 | 对 bg-0 1.12:1 |
| `--s-surface-2` | `#1E262E` | H210 S21% L15% | KPI 块、卡内嵌套、次级按钮 | 对 surface-1 1.12:1 |
| `--s-surface-3` | `#28323B` | H208 S19% L19% | 浮层：抽屉、tooltip、下拉、popover | 对 surface-2 1.17:1 |
| `--s-surface-inset` | `#0E1418` | H204 S26% L7% | 下沉：输入框、图表绘图区、表头、占比条轨道 | 比所在卡片更沉一级 |

| 令牌 | HEX | HSL | 说明 |
|---|---|---|---|
| `--s-accent` | `#2AC3D4` | H186 S67% L50% | 主青，对 surface-1 **8.06:1**、对 bg-0 9.03:1 |
| `--s-accent-strong` | `#55D6E4` | H186 S73% L61% | primary 按钮 hover / 焦点外环高亮 |
| `--s-accent-muted` | `#1C8B99` | — | 禁用态主色、空状态线性图标 |
| `--s-accent-bg` | `rgba(42,195,212,.12)` | — | selected 背景、ghost 按钮 hover 背景 |
| `--s-accent-border` | `rgba(42,195,212,.42)` | — | 选中细边光描边 |
| `--s-accent-glow` | `rgba(42,195,212,.28)` | — | 辉光扩散色 |

**允许**（白名单，共 6 项）：① 选中态 / 时间窗 chip / 当前 tab；② `:focus-visible` 焦点外环；③ 60 日情绪分主曲线与末端当前值微光点；④ primary 主按钮实底；⑤ 可点击链接与下钻入口；⑥ 系统「完成 / 已刷新」态标识。

**禁止**（黑名单）：① 用于**涨/跌数值**（涨跌专色见 §2.5）；② 大面积背景或整页渐变；③ 卡片常态描边、分隔线、图标装饰；④ 表格行斑马纹；⑤ 系统「成功 / 失败」的语义表达（避免与市场涨跌语义打架）；⑥ 与红/绿同时出现在同一数字串中。

### 2.5 语义色（A 股约定：**涨 = 红，跌 = 绿**）

> **约定写入**：本系统全部涨跌表达严格遵循中国 A 股惯例——**上涨、正收益、涨停、净买入为正 → 红；下跌、负收益、跌停、净买入为负 → 绿**。禁止套用欧美「绿涨红跌」。

| 类别 | 令牌 | 深色 HEX / HSL | 浅色 HEX / HSL | 用途 |
|---|---|---|---|---|
| 涨 / 正 | `--s-up` | `#F0595A` H360 S83% L65% | `#C62F32` H359 S62% L48% | 涨幅、涨停数、阳线、正净买 |
| 涨底 | `--s-up-bg` | `rgba(240,89,90,.12)` | `rgba(198,47,50,.10)` | 徽章底、占比条涨段 |
| 跌 / 负 | `--s-down` | `#2FC08B` H158 S61% L47% | `#0B7050` H161 S82% L24% | 跌幅、跌停数、阴线、负净买 |
| 跌底 | `--s-down-bg` | `rgba(47,192,139,.12)` | `rgba(11,112,80,.10)` | 徽章底、占比条跌段 |
| 持平 | `--s-flat` | `#8A97A2` H207 S11% L59% | `#5C6975` H209 S12% L41% | 平盘、无变化、中性 |
| 警报 | `--s-warn` | `#E6A63C` H37 S77% L57% | `#96620A` H38 S88% L31% | critical / warn 告警、阈值线 |
| 警报底 | `--s-warn-bg` | `rgba(230,166,60,.12)` | `rgba(150,98,10,.10)` | 告警徽章底 |
| 错误 | `--s-danger` | `#E8703F` H17 S79% L58% | `#C2410C` H17 S88% L40% | 系统错误 / 载入失败（**橙红，非涨红**） |
| 错误底 | `--s-danger-bg` | `rgba(232,112,63,.12)` | `rgba(194,65,12,.10)` | 错误提示底 |

**WCAG 校验（数值直接写在纯表面 `--s-surface-1` 上）**：

| 组合 | 深色 | 浅色（对 `#FFFFFF`） | 判定 |
|---|---|---|---|
| `--s-up` 文字 | **5.13:1** | **5.45:1** | 通过 AA（≥4.5） |
| `--s-down` 文字 | **7.38:1** | **6.09:1** | 通过 AA |
| `--s-flat` 文字 | 5.75:1 | 5.63:1 | 通过 AA |
| `--s-warn` 文字 | 8.08:1 | 5.19:1 | 通过 AA |
| `--s-danger` 文字 | 5.58:1 | 5.18:1 | 通过 AA |
| `--s-on-accent` / `--s-accent` | 8.53:1 | 4.91:1 | 通过 AA |
| `--s-control-border` 边界 | 3.46:1 / 3.73:1 | 3.73:1（`#788692`） | 通过 1.4.11（≥3.0） |

> 浅色跌绿初值 `#0E8A5F` 实测仅 **4.36:1**（不达标），已下调为 `#0B7050`（6.09:1）。

**徽章/标签的色彩纪律（重要）**：语义色**文字**压在语义色**底**上会掉到 4.00–4.45:1，不达标。因此徽章统一为「**语义色底(12%/10%) + 语义色 1px 描边(40%) + 6px 语义色圆点**，文字一律用 `--s-text-1` / `--s-text-2`」。实测合成底上文字对比度：深色 10.51–11.53:1（text-1）、6.23–6.83:1（text-2）；浅色 14.60–14.89:1（text-1）、7.19–7.34:1（text-2）。**只有「数值型涨跌幅」才允许直接用 `--s-up` / `--s-down` 作文字色，且必须写在纯表面上。**

**系统状态不使用纯红/纯绿**：完成、成功、已刷新 → 复用 `--s-accent`；警告 → `--s-warn`；失败/错误 → `--s-danger`（橙红）。这样红绿两个色相被**独占**给市场涨跌，避免「红=涨」与「红=错误」在同一屏互相污染。

### 2.6 辉光只允许三处（具体落点）

| # | 落点 | 组件与触发态 | 令牌 | 动画 | `prefers-reduced-motion` 降级 |
|---|---|---|---|---|---|
| ① | **选中细边光** | 时间窗 chip（20/30/60/90）、当前 tab、`[aria-selected="true"]` 卡片与表格行 | `--s-shadow-glow` | **静态**，仅切入时 `opacity` 160ms | 静态，无过渡 |
| ② | **警报呼吸** | 13 条状态中的 `critical` 级告警条（**仅 critical，非全部**） | `--s-shadow-alert` + `--s-warn` | `opacity` 0.55↔1，`2400ms` `ease-in-out` **infinite**（全站唯一无限循环） | 静态 `opacity:1` + 静态 1px 琥珀描边，不闪烁 |
| ③ | **主图当前值微光点** | 60 日情绪分曲线末端当前值（8px 实心点 + 12px 光晕） | `--s-shadow-value` + `--s-accent-glow` | `scale` 1→1.12，`2400ms` `ease-in-out` infinite | 静态点 + 静态光晕 |

**除此三处，全站任何按钮、卡片、标题、图标、徽章、表格、ticker 一律禁止 `box-shadow` 彩色光晕、发光边框、呼吸、闪烁、彩色投影。** 允许的阴影只有 `--s-shadow-1/2/3`（纯黑层级阴影）与 `--s-shadow-focus`（焦点环）。

| `hover` | 只改 `border-color` / 叠加 `--s-surface-hover`；时长 `--s-dur-instant` 100ms | 位移、缩放、改变宽高、`box-shadow` 扩散（会触发重排与 CLS） |

## 7. 动效与降级

### 7.1 允许清单（仅 opacity / transform）

| 允许 | 用途 | 时长 |
|---|---|---|
| `opacity` | hover 反馈、tooltip 显隐、骨架呼吸、警报呼吸（辉光 ②）、视图淡入 | 100–2400ms |
| `transform: translateX` | ticker 轨道滚动 | 线性连续 |
| `transform: translateY / translateX` | 抽屉滑入 | 240ms |
| `transform: scale` | 主图当前值微光点脉冲（辉光 ③） | 2400ms |
| `transform: rotate` | 按钮内联 spinner | 1000ms linear infinite |

### 7.2 禁止清单

| 禁止 | 原因 |
|---|---|
| `backdrop-filter` / `filter: blur()` | BRIEF 明确记录树莓派掉帧 |
| `background-color` / `color` / `border-color` 的**过渡动画** | 允许 hover **瞬时切换**，禁止 tween（避免重绘掉帧） |
| `width` / `height` / `top` / `left` / `margin` / `padding` 动画 | 触发重排与 CLS（BRIEF 3.3 的 CLS 治理反噬） |
| `box-shadow` 颜色/扩散动画 | 掉帧；辉光只允许静态或 opacity 呼吸 |
| 视差、滚动监听动画、盒中盒滚动惯性 | 与「整页滚动、零盒内滚动」纪律冲突 |
| 闪烁频率 > 3Hz、大面积渐变动画 | 可访问性与性能 |
| 任何锁死容器高度 + `overflow-y:auto` 的「防跳动」手段 | 见 §10 反模式 4–5 |

### 7.3 时长与缓动令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--s-dur-instant` | 100ms | hover / focus 反馈 |
| `--s-dur-fast` | 160ms | 按钮、tooltip、chip 切换、刷新完成脉冲 |
| `--s-dur-base` | 240ms | 抽屉滑入、面板/视图切换 |
| `--s-dur-slow` | 400ms | 跨视图淡入 |
| `--s-dur-breathe` | 2400ms | 警报呼吸 ② 与当前值脉冲 ③（唯一无限循环节奏） |
| `--s-ease` | `cubic-bezier(0.2, 0, 0.2, 1)` | 默认 |
| `--s-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 进入（抽屉、tooltip） |
| `--s-ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 呼吸与循环 |

### 7.4 `prefers-reduced-motion: reduce` 降级表

| 元素 | 默认 | reduce |
|---|---|---|
| 全部 `transition` / `animation` 时长 | 按上表 | 令牌全部覆盖为 `0.01ms`，并加 `animation-iteration-count: 1` |
| 警报呼吸 ② | `opacity` 0.55↔1 / 2400ms infinite | `animation: none`；静态 `opacity: 1` + 静态 1px `--s-warn` 描边 |
| ticker 轨道 | `translateX` 连续滚动 | `transform: none`，静态不滚，内容横向可手动查看 |
| 骨架屏 | `opacity` 呼吸 1200ms | 静态 `opacity: .7` |
| 抽屉滑入 | `translateY/X` 240ms | 直接显示（`opacity` 0.01ms） |
| 当前值微光点 ③ | `scale` 脉冲 | 静态 8px 点 + 静态 12px 光晕 |
| spinner | `rotate` 1000ms infinite | `animation: none`，保留「载入中…」文字 + 静态圆点 |
| 刷新反馈 | 160ms `opacity` 脉冲 | 只保留静态「已是最新」文字 |
| hover 反馈 | 100ms | 保留瞬时颜色切换（非运动），不做位移 |

**降级后状态仍须可感知**：loading 靠文字而非动画、告警靠静态高对比描边而非闪烁、完成靠静态文字而非脉冲。

> **运行时权威**：下列代码与 `prototype/tokens.css` 逐字一致，可整段复制即用；`prototype/components.css` 只消费本段变量，不写死任何颜色。这是本次交付唯一生效的令牌实现。
>
> **与第 2–4 节的关系**：色板 / 字阶 / 间距表是设计推导过程与对比度验算记录；同名令牌若与本段存在微差（例如 `--s-accent` 取 `#35d6d0`、`--s-space-10` 取 `64px`、阴影 blur 收敛到 12px 以内），**一律以本段为准**。收敛原因有两条：① 复算 WCAG 对比度后的色值微调；② BRIEF 第 1.C 节的树莓派性能纪律——禁用大 blur 阴影，故 `--s-shadow-3` 复用 `--s-shadow-2`。

## 9. 主题与可访问性

### 9.1 对比度下限（实测值见 §2）

| 对象 | 下限 | 本方案实测 |
|---|---|---|
| 正文文本（<24px） | **4.5:1**（WCAG AA 1.4.3） | `--s-text-1` 14.80 / `--s-text-2` 8.77 / `--s-text-3` 4.90；语义色 5.13–8.08 |
| 大字（≥24px 或 ≥19px 粗体） | **3:1** | display 56px 用 `--s-accent` 8.06:1；kpi 32px 用 `--s-text-1` 14.80:1 |
| UI 组件边界 / 图形（1.4.11） | **3:1** | `--s-control-border` 3.46 / 3.73；焦点环 8.06（深）/ 4.91（浅） |
| 禁用态 | 豁免 | 2.35（深）/ 2.49（浅）；必须同时有 `aria-disabled="true"` 与 `cursor: not-allowed`，不承载信息 |
| chrome 边框 | 不受 3:1 约束 | 1.09–1.81:1；因为外框**不是**组件的唯一识别手段（靠明度差 + 内容分组 + 阴影） |

浅色主题同样校验：`--s-text-1` 17.89、`--s-text-2` 8.81、`--s-text-3` 4.94、`--s-accent` 4.91、`--s-up` 5.45、`--s-down` 6.09、`--s-warn` 5.19、`--s-danger` 5.18、`--s-on-accent` 4.91（均对 `#FFFFFF`）。

### 9.2 焦点可见

- 全局 `:focus-visible` 使用 **双层实心环** `--s-shadow-focus`：`0 0 0 2px var(--s-surface-1), 0 0 0 4px var(--s-accent)`。内环隔离控件描边，外环为实色 `--s-accent`（深色 8.06:1、浅色 4.91:1，**≥3:1**）。浮层内控件把内环替换为 `--s-surface-3`。
- 禁止 `outline: none` 而无替代；禁止半透明焦点环（实测 50% accent 对底仅 3.00 / 2.06:1，浅色不达标）。
- 键盘可达顺序与 BRIEF 3.6 已验证资产一致：`/` 聚焦搜索、`1-6` 跳分区、`<details>` 折叠、抽屉入口、`-` 数据范围切换（BRIEF 3.5 明确 `-` 是 30 日精简档 ↔ 265 日完整档的**数据范围切换**，不是布局切换）。

### 9.3 色盲冗余（不能只靠红绿传意）

实测红绿**亮度比仅 1.44:1（深色）/ 1.12:1（浅色）**，几乎等亮，红绿色觉障碍下无法分辨。因此强制三重冗余：

| 场景 | 冗余手段（必须同时具备 ≥2 项） |
|---|---|
| 涨跌幅 / 涨跌家数 | ① `--s-up` / `--s-down` 色；② **↑ / ↓ 箭头**；③ **+ / − 正负号**；④ 文字「涨 / 跌」 |
| K 线 | ① 红/绿实体；② tooltip 内「涨 / 跌」文字 + ↑↓；③ 影线方向；④ 成交量柱同色 |
| 图表多序列 | ① 不同色相；② **实线 / 虚线 / 点线**线型；③ 图例文字；④ 数据点形状（圆 / 方 / 三角） |
| 占比条 / 环形仪表 | 每段带文字标签；环配文字图例；禁止仅靠色块区分 |
| 告警分级 | ① 颜色（琥珀 / 中性）；② 图标（⚠ / ⓘ）；③ 文字前缀「严重 / 提示 / 信息」；④ critical 才有呼吸辉光 |
| 系统状态 | 完成 = 青 + 文字「已刷新 / 已是最新」；错误 = 橙红 + ⚠ + 文字；不使用纯红/纯绿 |

### 9.4 触控目标与缩放

- 所有可点元素（按钮、chip、tab、图标按钮、表格可点行、抽屉关闭按钮）**≥ `--s-touch-min` 44px**；移动端按钮默认高 44px、表格行 44px、关闭按钮 `44×44`、时间窗 chip `≥44×44`。
- 相邻目标间距 ≥ `--s-space-2` 8px。
- 字号全部 `rem`，浏览器 200% 缩放不裁切；正文 `line-height 1.65` 且不锁死容器高度（解决 BRIEF 3.4 折行后半截字裁切）。
- 主题切换只用 `<html data-theme="light">` 属性覆盖，**不新增类名体系、不新增第三套选择器前缀**。
