## 3. 决策 1：否决桥接，改自行 fetch

### 3.1 为什么否决 `window.__btData = BT`

1. **偏离权威架构**：05 册 L145 阶段 3「改动文件：无」，加桥接改了 app.js。
2. **触碰数据层**：项目铁律是「数据层零改动」。虽然只读引用不改渲染逻辑，但既然有零触碰的等价路径，就不该选触碰路径。
3. **破坏阶段自包含**：加桥接后，工作台净值曲线依赖研报脚本 `loadBacktest()` 成功挂载 window；研报侧一旦异常，工作台连带受损。自行 fetch 则完全解耦。
4. **先例不可类推**：`__isNewStock`/`window.Seats` 是判据函数，fetch 替代不了；净值是静态数据，fetch 足够。

### 3.2 采纳方案：工作台自行 fetch + 自建独立 chart

实现路径：

1. `s-page-backtest.js` 自行 `fetch('./data/backtest.json?_=' + Date.now(), { cache:'no-store' })`，取 `json.series`（`dates/navBase/navV52/navV53/navHold`）。
2. 按 `app.js:2286-2295` 同口径构造展示 series：
   - `{ name:'V5 基准（无成本/无风控）', values:s.navBase||[], color:'var(--muted)', dash:true }`
   - `{ name:'V5.2 增强（成本+平滑+风控）', values:s.navV52||[], color:'var(--acc)' }`
   - `s.navV53?.length` 时追加 V5.3 动态仓位（`var(--ok)`）
   - `{ name:'等权指数买入持有', values:s.navHold||[], color:'var(--warn)', dash:true }`
3. 在 `#btNavHost`（`data-chart="bt-nav"`）上 `window.LightweightCharts.createChart(...)`，**用工作台自己的 chart 变量保存实例**，绝不引用 `_navChart`。
4. 按 04 册蓝图建 `#btMetrics` 4 KPI + `#btNavChart`/`#btNavHost`；`data-state` 从 `pending` → `ready`（或 `error`）。
5. 离开 tab 时 `chart.remove()`，配合全局单例 tooltip 清理，避免残留（05 册风险项 6）。
6. 白屏②：8 秒上限 + 超时/失败回退到可重试态，不永久停在 pending（05 册风险项 3/7）。

**诚实说明代价**：
- 多一次静态 JSON 请求（63KB，成本可忽略），且天然同源。
- 工作台需重写 series 的 `name/color/dash` 展示元数据。这属于 **UI 展示层职责**，数值全部来自 JSON、不重算任何指标，与项目禁止的「判据/计算口径副本」（`isNewStock` 那类）性质不同，不触发审计问题。
