# 04 页面蓝图与组件规格

> Phase 3 · 前端落地规格与迁移映射
> 事实底座：`design/BRIEF.md`（2026-11-14 线上真实渲染侦察）。本文只描述展示层，**不改线上代码、不改 app.js / bundle.js 的数据逻辑、不改 34 个 `data/*.json`**。
> 配套可运行样式：`design/prototype/tokens.css`（151 个 `--s-*` 令牌）、`design/prototype/components.css`。
> 本文所有结论均取自 BRIEF 第 1、2、3、5 节实测；不引用第 4 节已证伪的旧结论。

## 0. 硬契约

### 0.1 命名与作用域

| 项 | 契约 |
|---|---|
| 设计令牌 | 一律 `--s-*`，定义在 `:root`；浅色由 `[data-theme="light"]` 覆盖 |
| 根作用域 | `.s-scope`，所有基础重置（含 `box-sizing`）严格限定在该作用域内 |
| 类名 | BEM 风格，前缀 `s-`；元素 `__`，修饰 `--`；状态用 `.is-*` / `aria-*` / `[data-*]` |
| 局部令牌 | `--s-col-w`（表格列宽，行内提供）、`--s-sticky-offset`（表头吸顶偏移，`.s-scope` 提供），均带 fallback |
| 断链 | `xs <640` 手机 / `sm 640-1023` 平板 / `md 1024-1439` 小桌面 / `lg >=1440` 桌面 |
| 滚动模型 | `.s-main` 整页滚动、零盒内滚动；盒内滚动白名单只有 `.s-drawer__body` 与 `.s-table__viewport`（仅虚拟滚动时启用） |
| 颜色 | 组件样式只取 `var(--s-*)`；红涨绿跌（A 股约定） |
| 动效 | 只做 `opacity` / `transform`，`prefers-reduced-motion` 降级；禁用毛玻璃类滤镜与大 blur 阴影 |

### 0.2 契约扩展类（与高保真原型对齐）

### 0.3 代码块使用约定

- 第 1 章每个代码块**自包含**：外层带 `.s-scope` 与 `.s-main`，粘贴到空 `body` 即可静态渲染出真实版式（需先 `<link>` 引入 `tokens.css` 与 `components.css`）。
- 集成到主视图 shell 时：**删除片段外层的 `.s-scope` 与 `.s-main`**，只把 `<section class="s-page">` 及其内容挂到 shell 的 `.s-main` 内。
- 代码块内的示例数值（38.4 / 冰点 / 37 / 33 / 755 / 4472 / -0.77 亿 / 数据日 2026-11-13）来自 BRIEF 实测的正常数据态，仅用于校验版式，运行时一律由现有 render 函数原位替换。
- 所有代码块使用标准 ASCII 标识符与标点；中文只出现在文本节点与注释中；**无省略占位、无截断**。
- 代码片段不引用任何外部依赖；JS 伪代码用 `S.*` 命名空间表示新增适配层，不改动既有函数。

### 0.4 数据边界

34 个 `data/*.json` 与 54 个 `function render*`（app.js 38 + bundle.js 17，去重后 54），其中 bundle.js 的 `renderStats / renderPositions / renderOrderForm / renderSysPanel / renderPicks / renderLogs` 等**保持零改动**。新增的适配层只做两件事：

1. 订阅既有 render 的输出，把内容搬到新的 `.s-*` 容器（DOM 搬迁，不重算）；
2. 用骨架占位与原位替换解决 CLS，不改取值口径。

### 4.3 原位替换 JS 伪代码

```js
(function (S) {
  "use strict";

  S.replaceSkeleton = function replaceSkeleton(host, buildNodes, options) {
    var opt = options || {};
    var before = host.getBoundingClientRect();
    var skel = host.querySelector("[data-skeleton]") || host.firstElementChild;

    host.setAttribute("aria-busy", "true");

    var frag = document.createDocumentFragment();
    var nodes = buildNodes();
    for (var i = 0; i < nodes.length; i += 1) {
      frag.appendChild(nodes[i]);
    }

    // 先插入真实节点、再移除骨架，两帧之间容器高度始终有内容支撑
    host.insertBefore(frag, skel);
    if (skel && skel.parentNode === host) {
      host.removeChild(skel);
    }

    host.removeAttribute("aria-busy");

    var after = host.getBoundingClientRect();
    var shift = Math.abs(after.top - before.top);
    if (opt.onShift) {
      opt.onShift(shift, before, after);
    }
    return shift;
  };

  S.mountKpiRow = function mountKpiRow(host, items) {
    return S.replaceSkeleton(host, function () {
      return items.map(function (it) {
        var box = document.createElement("div");
        box.className = "s-kpi" + (it.danger ? " s-kpi--danger" : "");
        var label = document.createElement("span");
        label.className = "s-kpi__label";
        label.textContent = it.label;
        var value = document.createElement("span");
        value.className = "s-kpi__value";
        value.textContent = it.value;
        var delta = document.createElement("span");
        delta.className = "s-kpi__delta";
        delta.textContent = it.delta;
        box.appendChild(label);
        box.appendChild(value);
        box.appendChild(delta);
        return box;
      });
    });
  };

  S.mountTable = function mountTable(host, rows, columns) {
    return S.replaceSkeleton(host, function () {
      var table = document.createElement("table");
      table.className = "s-table s-table--compact";
      var thead = document.createElement("thead");
      var htr = document.createElement("tr");
      columns.forEach(function (col) {
        var th = document.createElement("th");
        th.scope = "col";
        th.setAttribute("data-priority", String(col.priority));
        th.style.setProperty("--s-col-w", col.width);
        th.textContent = col.label;
        htr.appendChild(th);
      });
      thead.appendChild(htr);
      table.appendChild(thead);
      var tbody = document.createElement("tbody");
      rows.forEach(function (row) {
        var tr = document.createElement("tr");
        tr.tabIndex = 0;
        columns.forEach(function (col) {
          var td = document.createElement("td");
          td.setAttribute("data-priority", String(col.priority));
          td.textContent = row[col.key];
          if (col.numeric) { td.className = "s-num"; }
          tr.appendChild(td);
        });
        tbody.appendChild(tr);
      });
      table.appendChild(tbody);
      return [table];
    });
  };
}(window.S = window.S || {}));
```

关键点：`insertBefore` 先于 `removeChild`，容器任何时刻都不为空；骨架与真实节点共享同一父容器与同一 `--s-*` 尺寸令牌，因此 `getBoundingClientRect().top` 差值可断言为 0。第 5 章的自检脚本会把这个差值纳入骨架替换位移检测。

### 5.2 完整 HTML

见 1.1 shell 内的 `#sDrawerMask` / `#sDrawer` 与 1.7 的移动端 `#mSheet`。核心约束：

- 遮罩 `.s-drawer__mask` 与抽屉 `.s-drawer` 都用 `hidden` 属性做真隐藏（`tokens.css` 的 `.s-scope [hidden] { display: none !important }`）。
- 只有 `.s-drawer__body` 有 `overflow-y: auto`；head / foot 固定，`overscroll-behavior: contain` 阻断滚动穿透到整页。

### 5.3 JS 伪代码（焦点陷阱 / ESC / 滚动归属 / sheet 手势）

```js
(function (S) {
  "use strict";

  var FOCUSABLE = "a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex='-1'])";
  var state = { lastFocus: null, size: "md", open: false };

  function q(id) { return document.getElementById(id); }

  function focusables(root) {
    return Array.prototype.filter.call(root.querySelectorAll(FOCUSABLE), function (el) {
      return el.offsetWidth > 0 || el.offsetHeight > 0 || el === document.activeElement;
    });
  }

  S.openDrawer = function openDrawer(config) {
    var cfg = config || {};
    var drawer = q("sDrawer");
    var mask = q("sDrawerMask");
    if (!drawer || !mask) { return; }

    state.lastFocus = document.activeElement;
    state.size = cfg.size || "md";
    state.open = true;

    drawer.className = "s-drawer s-drawer--" + state.size;
    q("sDrawerTitle").textContent = cfg.title || "详情";
    q("sDrawerSub").textContent = cfg.sub || "数据日 2026-11-13";

    if (typeof cfg.render === "function") {
      cfg.render(q("sDrawerBody"));
    }

    drawer.hidden = false;
    mask.hidden = false;
    drawer.setAttribute("aria-hidden", "false");

    // 整页滚动归属：打开时锁 body，抽屉内部仍可滚
    document.documentElement.style.overflow = "hidden";
    document.body.style.overflow = "hidden";

    // 两帧后再加 is-open，保证 transform 过渡生效
    requestAnimationFrame(function () {
      requestAnimationFrame(function () {
        mask.classList.add("is-open");
        drawer.classList.add("is-open");
        q("sDrawerBody").scrollTop = 0;
        q("sDrawerClose").focus();
      });
    });
  };

  S.closeDrawer = function closeDrawer() {
    var drawer = q("sDrawer");
    var mask = q("sDrawerMask");
    if (!drawer || !state.open) { return; }
    state.open = false;

    drawer.classList.remove("is-open");
    mask.classList.remove("is-open");
    drawer.setAttribute("aria-hidden", "true");

    var finish = function () {
      drawer.hidden = true;
      mask.hidden = true;
      document.documentElement.style.overflow = "";
      document.body.style.overflow = "";
      if (state.lastFocus && typeof state.lastFocus.focus === "function") {
        state.lastFocus.focus();
      }
    };

    if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
      finish();
    } else {
      window.setTimeout(finish, 200);
    }
  };

  S.bindDrawer = function bindDrawer() {
    var drawer = q("sDrawer");
    var mask = q("sDrawerMask");
    if (!drawer) { return; }

    q("sDrawerClose").addEventListener("click", S.closeDrawer);
    q("sDrawerDone").addEventListener("click", S.closeDrawer);
    mask.addEventListener("click", S.closeDrawer);

    document.addEventListener("keydown", function (e) {
      if (!state.open) { return; }
      if (e.key === "Escape") {
        e.preventDefault();
        S.closeDrawer();
        return;
      }
      if (e.key !== "Tab") { return; }
      var list = focusables(drawer);
      if (list.length === 0) {
        e.preventDefault();
        q("sDrawerBody").focus();
        return;
      }
      var first = list[0];
      var last = list[list.length - 1];
      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    });

    // 移动端 sheet 手势：下拉超过 96px 或速度足够即关闭
    var grab = q("sDrawerGrab");
    var startY = 0;
    var startT = 0;
    var dy = 0;
    grab.addEventListener("touchstart", function (e) {
      startY = e.touches[0].clientY;
      startT = Date.now();
      dy = 0;
      drawer.style.transition = "none";
    }, { passive: true });
    grab.addEventListener("touchmove", function (e) {
      dy = e.touches[0].clientY - startY;
      if (dy > 0) {
        drawer.style.transform = "translateY(" + dy + "px)";
      }
    }, { passive: true });
    grab.addEventListener("touchend", function () {
      drawer.style.transition = "";
      drawer.style.transform = "";
      var elapsed = Math.max(Date.now() - startT, 1);
      var velocity = dy / elapsed;
      if (dy > 96 || velocity > 0.5) { S.closeDrawer(); }
    });
  };

  // 切 tab 时统一关闭抽屉并清理跨视图 tooltip 残留
  S.onTabChange = function onTabChange() {
    S.closeDrawer();
    var tip = q("sTooltip");
    if (tip) {
      tip.classList.remove("is-visible");
      tip.setAttribute("aria-hidden", "true");
      tip.textContent = "";
    }
  };

  S.setDrawerSize = function setDrawerSize(size) {
    var drawer = q("sDrawer");
    if (!drawer) { return; }
    drawer.classList.remove("s-drawer--sm", "s-drawer--md", "s-drawer--lg");
    drawer.classList.add("s-drawer--" + size);
  };
}(window.S = window.S || {}));
```

**滚动归属**：打开时 `html/body { overflow: hidden }`，关闭时恢复；抽屉自身不滚，只有 `__body` 滚。这与「整页滚动零盒内滚动」不冲突——抽屉是模态覆盖层，属于白名单。

## 6. 表格实现

### 6.1 列优先级方案

`data-priority` 取 1 至 4，写在 `<th>` 与对应 `<td>` 上；CSS 断点隐藏低优先级列（见 `components.css` 第 7 节）：

| 断点 | 显示列 | 隐藏列 |
|---|---|---|
| xs `<640` | `data-priority="1"` | 2 / 3 / 4 |
| sm `640-1023` | 1 / 2 | 3 / 4 |
| md `1024-1439` | 1 / 2 / 3 | 4 |
| lg `>=1440` | 1 / 2 / 3 / 4 | 无 |

列宽用行内 `--s-col-w` 提供，CSS 里 `width: var(--s-col-w, auto)`，全部走变量、无写死颜色；`table-layout: fixed` + `overflow-wrap: anywhere` 保证任何列数下都不撑破视口。**不使用 `overflow-x: auto`**，从根上消除 533px `dt-table` 式的横向溢出。

### 6.2 完整 HTML

见 1.3「涨停梯队与个股明细」、1.4「策略明细」、1.7「移动端涨停梯队」三处表格骨架，均含 `scope="col"`、`data-priority`、行内 `--s-col-w`、`tabindex="0"`、`aria-label` 与 `caption`。

### 6.3 表头吸顶

### 6.4 数百行分页 / 虚拟滚动阈值

| 行数 | 模式 | 策略 | 骨架契约 |
|---|---|---|---|
| `< 200` | `data-mode="all"` | 一次性渲染，表头吸顶 | 6 行等高骨架 |
| `200 - 1000` | `data-mode="pager"` | 每页 50 行，页码按钮 + 首/末页 | 每页 6 行等高骨架，切页不换容器 |
| `> 1000` | `data-mode="virtual"` | 视口内渲染 + 上下 spacer，行高固定 36px | 同上，spacer 高度 = 行数 x 36px |

虚拟滚动只在 `.s-table__viewport` 上启用，且此时它是唯一被允许的盒内滚动容器；一旦启用，`.s-table thead` 需改为容器内 sticky（`top: 0`），由适配层切换类名。

```js
(function (S) {
  "use strict";

  S.ROW_H = 36;
  S.PAGE_SIZE = 50;

  S.chooseTableMode = function chooseTableMode(total) {
    if (total > 1000) { return "virtual"; }
    if (total >= 200) { return "pager"; }
    return "all";
  };

  S.paginate = function paginate(rows, page) {
    var size = S.PAGE_SIZE;
    var start = page * size;
    return rows.slice(start, start + size);
  };

  S.renderVirtual = function renderVirtual(cfg) {
    var viewport = cfg.viewport;
    var tbody = cfg.tbody;
    var total = cfg.total;
    var rowHeight = S.ROW_H;

    function paint() {
      var scrollTop = viewport.scrollTop;
      var visible = Math.ceil(viewport.clientHeight / rowHeight) + 6;
      var first = Math.max(0, Math.floor(scrollTop / rowHeight) - 3);
      var last = Math.min(total, first + visible);
      var topPad = document.createElement("tr");
      var topCell = document.createElement("td");
      topCell.colSpan = cfg.columns.length;
      topCell.style.height = (first * rowHeight) + "px";
      topCell.style.padding = "0";
      topCell.style.border = "0";
      topPad.appendChild(topCell);
      var bottomPad = document.createElement("tr");
      var bottomCell = document.createElement("td");
      bottomCell.colSpan = cfg.columns.length;
      bottomCell.style.height = ((total - last) * rowHeight) + "px";
      bottomCell.style.padding = "0";
      bottomCell.style.border = "0";
      bottomPad.appendChild(bottomCell);
      tbody.replaceChildren(topPad);
      for (var i = first; i < last; i += 1) {
        tbody.appendChild(cfg.buildRow(cfg.rows[i], i));
      }
      tbody.appendChild(bottomPad);
    }

    viewport.addEventListener("scroll", function () {
      if (S._vtFrame) { return; }
      S._vtFrame = requestAnimationFrame(function () {
        S._vtFrame = 0;
        paint();
      });
    }, { passive: true });
    paint();
    return paint;
  };
}(window.S = window.S || {}));
```

## 7. 图表容器

### 7.1 响应式尺寸契约

- 所有图表容器用 `aspect-ratio: var(--s-chart-ratio)`（默认 16/9，`--wide` 21/9，`--square` 1/1，`--fixed` 用 `--s-skel-chart-h: 280px`）。
- 骨架 `.s-skeleton--chart` 与真实 `.s-chart` 共用同一 `aspect-ratio`，替换零位移。
- 容器 `position: relative`，内部 `.s-chart__host { position: absolute; inset: 0 }`，`canvas` / `svg` 均 `width: 100%; height: 100%`。
- 用 `ResizeObserver` 监听容器而非 `window.resize`，避免 tab 切换后尺寸为 0。

### 7.2 完整 HTML

见 1.2 的 `#sTrendChart` / `#sFactorChart`、1.4 的 `#btNavChart`、1.7 的 `#mTrendChart`。三者都带 `data-state="pending"`、`data-chart` 类型标记、`.s-chart__pending` 占位、`.s-chart__host` 挂载点，情绪分主图额外有 `.s-chart__dot`（辉光三处之一：当前值微光点，只做 opacity 呼吸）。

### 7.3 lightweight-charts 接入点

现有外链 `vendor/lightweight-charts` 保持不动，只在 K线 tab 与选股下钻抽屉内挂载：

```js
(function (S) {
  "use strict";

  S.mountLightweightChart = function mountLightweightChart(cfg) {
    var chart = document.getElementById(cfg.chartId);
    var host = document.getElementById(cfg.hostId);
    if (!chart || !host || typeof window.LightweightCharts === "undefined") {
      chart && chart.setAttribute("data-state", "error");
      return null;
    }

    var api = window.LightweightCharts.createChart(host, {
      width: host.clientWidth,
      height: host.clientHeight,
      layout: {
        background: { color: getComputedStyle(chart).backgroundColor },
        textColor: getComputedStyle(chart).color
      },
      grid: { vertLines: { visible: false }, horzLines: { visible: false } },
      timeScale: { borderVisible: false },
      rightPriceScale: { borderVisible: false }
    });

    var series = api.addCandlestickSeries({
      upColor: getComputedStyle(document.documentElement).getPropertyValue("--s-up").trim(),
      downColor: getComputedStyle(document.documentElement).getPropertyValue("--s-down").trim(),
      borderVisible: false,
      wickUpColor: getComputedStyle(document.documentElement).getPropertyValue("--s-up").trim(),
      wickDownColor: getComputedStyle(document.documentElement).getPropertyValue("--s-down").trim()
    });
    series.setData(cfg.bars);

    var ro = new ResizeObserver(function (entries) {
      var rect = entries[0].contentRect;
      api.applyOptions({ width: Math.floor(rect.width), height: Math.floor(rect.height) });
      api.timeScale().fitContent();
    });
    ro.observe(host);

    chart.setAttribute("data-state", "ready");
    S._chartCleanup = S._chartCleanup || [];
    S._chartCleanup.push(function () { ro.disconnect(); api.remove(); });
    return api;

```

配色从 `getComputedStyle(document.documentElement).getPropertyValue("--s-up")` 与 `getPropertyValue("--s-down")` 读取，红涨绿跌由令牌决定，组件里不写死颜色。

### 7.4 SVG K线接入点

`trendSvg`（60 日情绪分）与 K线 tab 的 664 根日K 均为 SVG，接入点是把既有 render 产出的 SVG 搬进 `.s-chart__host`，并用 `viewBox` + `preserveAspectRatio` 适配容器：

```js
(function (S) {
  "use strict";

  S.mountSvgChart = function mountSvgChart(cfg) {
    var chart = document.getElementById(cfg.chartId);
    var host = document.getElementById(cfg.hostId);
    if (!chart || !host) { return null; }

    var svg = cfg.buildSvg();
    svg.setAttribute("viewBox", cfg.viewBox || "0 0 960 540");
    svg.setAttribute("preserveAspectRatio", "none");
    svg.setAttribute("role", "img");
    svg.setAttribute("aria-label", cfg.label || "走势图");
    svg.style.width = "100%";
    svg.style.height = "100%";
    host.replaceChildren(svg);
    chart.setAttribute("data-state", "ready");

    var ro = new ResizeObserver(function (entries) {
      var w = Math.max(1, Math.floor(entries[0].contentRect.width));
      var h = Math.max(1, Math.floor(entries[0].contentRect.height));
      svg.setAttribute("viewBox", "0 0 " + w + " " + h);
      if (typeof cfg.onResize === "function") { cfg.onResize(w, h); }
    });
    ro.observe(host);
    return ro;
  };
}(window.S = window.S || {}));
```

`preserveAspectRatio="none"` 配合动态 `viewBox` 使既有 664 根蜡烛在 390px 与 1440px 下都能铺满容器且不失真性裁切；若既有 render 输出自带 viewBox，则保留其比例并改用 `xMidYMid meet`。

### 7.5 懒挂载与清理

```js
(function (S) {
  "use strict";

  S.lazyCharts = function lazyCharts() {
    var nodes = document.querySelectorAll(".s-chart[data-state='pending']");
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (entry) {
        if (!entry.isIntersecting) { return; }
        var el = entry.target;
        var kind = el.getAttribute("data-chart");
        if (kind === "trend-svg" || kind === "bt-nav") {
          S.mountSvgChart({
            chartId: el.id,
            hostId: el.querySelector(".s-chart__host").id,
            buildSvg: S.buildExistingSvg,
            label: el.getAttribute("aria-label")
          });
        } else if (kind === "lightweight") {
          S.mountLightweightChart({
            chartId: el.id,
            hostId: el.querySelector(".s-chart__host").id,
            bars: S.readExistingBars()
          });
        }
        io.unobserve(el);
      });
    }, { rootMargin: "200px 0px" });
    nodes.forEach(function (n) { io.observe(n); });
    return io;
  };

  S.disposeCharts = function disposeCharts() {
    (S._chartCleanup || []).forEach(function (fn) { fn(); });
    S._chartCleanup = [];
  };
}(window.S = window.S || {}));
```

`rootMargin: 200px 0px` 让首屏外一屏的图表提前挂载；切 tab 时调用 `S.disposeCharts()` 清理 lightweight-charts 实例与 ResizeObserver，避免 tooltip 残留与内存泄漏。

## 8. 本册自检

- 7 段 HTML 骨架全部自包含、含 aria、静态可渲染、无省略占位。
- 组件清单 24 行覆盖全部契约 class，数据来源落到 34 个只读 JSON。
- 迁移映射 67 行覆盖用户清单 47 个关键 id，处理方式只用 5 个约定值。
- 骨架尺寸契约与真实组件共用 `--s-*` 令牌，替换位移可断言为 0。
- 抽屉三档 + 全屏 sheet、焦点陷阱、ESC、滚动归属、手势伪代码齐备。
