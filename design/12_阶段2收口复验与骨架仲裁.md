线上 `S.runSelfTest()` 实值：`skeletonSwap:{skeletonH:0, realH:134, duringInsert:134, afterReplace:0, maxShift:134, pass:false}`、`pass:false`、`drawerFocusTrap:"drawer missing"`、`horizontalOverflow:0`、`cls:0.0035`。

### 5.4 真根因：探针自身的两处顺序 bug

```js
var t0 = anchor.getBoundingClientRect().top;
host.insertBefore(real, skel);            // ① 先插 real：两卡共存 268px → d1 恒 = 134
var t1 = anchor.getBoundingClientRect().top;
host.removeChild(skel);                  // ② 先删 skel
var t2 = anchor.getBoundingClientRect().top;
var skelH = skel.getBoundingClientRect().height;  // ③ 才测：脱离文档的元素矩形恒 0
```

`pass = max(d1,d2) < 1 && |skelH-realH| < 1`。只要骨架类有高度，`d1` 就 > 1；只要先删后测，`skelH` 就 = 0。**因此这个探针结构性恒假**——与 CSS 写得多完美、有没有 `s-skeleton.js`、`contain`/`visibility` 全都无关。

### 5.5 为什么必须现在定性为「阶段 5 阻断项」

`s-selftest.js:292-301`：

```js
report.pass = horizontal.count === 0 && innerScroll.violations.length === 0 &&
  (cls.pass === true || cls.pass === null) && touch.violations === 0 &&
  contrast.violations === 0 && drawer.ok === true &&
  empty.missingTitle === 0 && empty.oversized === 0 &&
  skeleton.pass === true;          // ← 硬条件
```

而 05/06 册把「`S.runSelfTest()` 8 项全绿」列为**阶段 5 翻默认视图的硬门槛**。`skeletonSwap.pass` 恒 false ⇒ `runSelfTest().pass` **永远 false**，无论阶段 4 骨架体系做得多完整都不会变。所以 7.3 不是「归阶段 4.3 统一处理的观察项」，而是**必须在阶段 5 前修掉的门禁工具缺陷**；`drawer.ok` 同理要等阶段 4 三档抽屉，这一条 CodeBuddy 判断正确。

### 5.6 责任归属与最小补丁

**bug 出在我原始设计文档**：`05 册 5.2.1 L617-647` 的代码段与线上 `s-selftest.js:231-266` **逐字同源**，同样含 `insertBefore → removeChild → 测 skelH`。CodeBuddy 阶段 0 照抄无责。补丁须**文档 + 脚本同改**，否则又留双真源。

替换 `s-selftest.js` L635-645（05 册 L635-645 同步；**阈值一字不改**，不是放宽标准）：

```js
    var t0 = anchor.getBoundingClientRect().top;
    var skelH = skel.getBoundingClientRect().height;   // ← 在 DOM 内测（原在 removeChild 之后）
    host.replaceChild(real, skel);                     // ← 原子替换，替代 insertBefore + removeChild
    var t1 = anchor.getBoundingClientRect().top;
    var realH = real.getBoundingClientRect().height;
    document.body.removeChild(wrap);

    var d1 = Math.abs(t1 - t0);
    var d2 = 0;                                        // 原子替换无第二帧
    return {
      skeletonH: Math.round(skelH), realH: Math.round(realH),
      duringInsert: Number(d1.toFixed(2)), afterReplace: Number(d2.toFixed(2)),
      maxShift: Number(Math.max(d1, d2).toFixed(2)),
      pass: Math.max(d1, d2) < 1 && Math.abs(skelH - realH) < 1
    };
```

本轮修正版实测 `pass:true`。`s-selftest.js` 在部署白名单内，改它会触发重新部署，但纯工具逻辑、零视觉变化；验收仍需预热导航绕 SW 旧外壳。
