## 3. 阶段 1：影子挂载（双根共存，仅深链可见）

**新增**：`#sRoot.s-scope.s-app`（默认 `hidden`）、`s-mount.js`（shell / 8 tab 路由 / ticker / tooltip 单例）、`s-adapter.js`（LINK 订阅 + MutationObserver 骨架）、`s-flags.js`。仅 `?view=workbench` / `#workbench` 可见；`?view=terminal` 零变化。

> **【WB 修订 R2】这是全单最要紧的一处：初稿的深链验收是空门禁。**
> 原命令 `for u in "" "?view=terminal" "?view=workbench"; do curl -s -o /dev/null -w "%{http_code} $u" ...; done` 有两个致命问题：
> 1. **GitHub Pages 静态托管，任何 query string 都返回同一份 `index.html` 200**——深链映射有没有实现、有没有语义反转，三条都是 200；
> 2. **`#terminal` / `#workbench` 是 fragment，curl 根本不把它发给服务器**，`curl ".../#terminal"` 等价于 `curl ".../"`。05 册 V1-2 / V5-3 自带此缺陷，初稿照抄，且阶段 1 连 `#workbench` 都漏测了。
>
> 而阶段 5 硬门槛「深链幂等映射灰度 7 天、可达率 100%」的数据源正是这条命令 —— **用 curl 采出来的 100% 是假的**。

**替换后的验收命令**：

```bash
# 逐条 URL 导航后检查渲染态 DOM，而非 HTTP 状态码
node design/verify_phase_gates.cjs links \
  --url=https://sjc19950404.github.io/a-sentiment-pro/ --stage=1
```

| URL | 期望主根 | 断言 |
|---|---|---|
| `/` | 研报 | `main` 可见且 `aria-hidden !== "true"`；`#tRoot` hidden；`#sRoot` hidden |
| `?view=terminal` | 终端 | `#tRoot` 可见（`main` 被 `.t-scope` fixed 覆盖层遮挡，不参与 `activeRoots`）；`#sRoot` hidden |
| `?view=workbench` | 工作台影子根 | `#sRoot` 可见且子节点非空；另两根 hidden |
| `#workbench` | 工作台影子根 | 同上（**初稿漏项**） |
| 二次导航 → 返回 → 再进入 | 幂等 | 活跃主根数量恒为 1，无叠加、无残留浮层 |

再加 05 册原有两条：`S.runSelfTest()` 8 项全绿；横向溢出元素数 = 0、盒内滚动容器数 = 0。

> **【WB 修订 R3】新增验收点③：终端 fixed 入口按钮的隔离。**
> 05 册 L290 与初稿都写「用 `.s-scope ~ .t-entry { display:none }` 隐藏⚡图表终端按钮」。**线上源码里 `.t-entry` 出现 0 次**——真实代码（`index.html` 内联 terminal.js 生成物，约 L3384）是：
> ```js
> const entry = el('button', '', '⚡ 图表终端');   // 第二个参数即 className，传的是空串
> entry.style.cssText = 'position:fixed;top:8px;right:12px;z-index:9998;...';
> document.body.appendChild(entry);                // 无 id、无 class、无 data-*，全内联样式
> ```
> 三个后果：
> - `.t-entry` 选择器**永不匹配**，规则静默失效；
> - `~` 还要求后续同级兄弟，而按钮挂在 `document.body` 末尾，`.s-scope` 若挂在容器内则根本不同级；
> - 按钮 `z-index: 9998`，高于方案给的 `--s-z-drawer: 910` / `--s-z-tooltip: 950`，**不处理就会一直浮在工作台抽屉和 tooltip 之上**。
>
> **正确做法（阶段 1 上线条件）**：改 `terminal.js` **源文件**（不是内联生成物）给按钮补稳定锚点 `entry.id = 't-entry'` 或 `data-t-entry`，再重新生成内联块；隐藏规则用 `#t-entry { display: none }` 并限定在 `.s-scope` 激活态（由 `s-flags.js` 在 `body` 上加 `[data-view="workbench"]`），**不要用 `~` 兄弟选择器**。验收断言：`body > button` 中文本含「图表终端」的元素，在工作台视图下 `getComputedStyle(...).display === 'none'`，且研报视图下仍可见可点。
>
> 补充：该按钮是 `position: fixed`，`offsetParent === null`——写可见性断言时**不能用 `offsetParent !== null` 过滤**，否则会漏检（此前侦察已踩过一次）。

**风险**：z-index 分层按 05 册 L290 的 `--s-z-*` 令牌，但需把 9998 这个历史值纳入回归检查。
