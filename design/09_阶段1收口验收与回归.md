## 2. 为什么 17/17 是假绿

`verify_phase_gates.cjs` 的 `vis()`：

```js
const vis = e => !!e && !e.hasAttribute('hidden') &&
  getComputedStyle(e).display !== 'none' && ...;
```

第一个条件 `!e.hasAttribute('hidden')` 一旦为 false 就短路，**后面的 `display !== 'none'` 永远不会执行**。所以只要元素带着 `hidden` 属性，探针就判定「不可见」，哪怕作者样式把 `[hidden]` 覆盖成 `display:flex`、`offsetHeight:874`。

这和上轮发现的「`activeRoots` 只统计 `tRoot`/`sRoot`，研报 `main` 漏检」是同一类问题：**只看属性/白名单，不看计算后的真实布局**。08 册补了 `mainVisible` 断言，但漏了影子根自身的「真隐藏」断言。本册补上。

## 3. 新 P0-A · `[hidden]` 被 `.s-app{display:flex}` 覆盖

### 证据（回归探针 `阶段1收口回归.json`）

| 用例 | `sRoot.hidden` | `computed.display` | `offsetHeight` | `rectTop` | `bodyScrollHeight` | 强制隐藏后 | **多出的空白** |
|---|---|---|---|---|---|---|---|
| 默认 `/`（整页） | `true` | **`flex`** | 908 | 9539 | **10447** | 9539 | **+908px** |
| `?view=terminal` | `true` | **`flex`** | 874 | 9539 | **10413** | 9539 | **+874px** |
| 同页 `popstate` 回默认 | `true` | **`flex`** | 908 | 9322 | **10230** | 9322 | **+908px** |

（`contribution` 字段由探针临时 `sRoot.style.setProperty('display','none','important')` 前后测量得出，测完恢复原 style。）

### 成因

- `s-components.css:29` `.s-app { display:flex; flex-direction:column; min-height:100vh; min-height:100dvh; ... }` 是**作者样式**；
- UA stylesheet 的 `[hidden] { display:none }` 优先级更低，全站 grep **没有任何** `.s-app[hidden]` 或全局 `[hidden]` 兜底规则（`index.html:103` 只在注释里写「hidden 时由 UA `[hidden]` 变 display:none」，事实并非如此）；
- `s-root.js` 用 `sRoot.hidden = true` 隐藏根 → 属性在，但**视觉完全没隐藏**，且 `min-height:100dvh` 让它撑满一屏。

### 影响

**阶段 5 前默认仍是研报视图**，而默认页现在从 9539px 变成 10447px —— 用户在研报页底部会滚到一整屏空白。这直接破坏 05 册 L97 / 06 册阶段 1 最核心的兼容边界「默认研报视图零变化」。`?view=terminal` 与 SPA 内 `popstate` 回退同样中招。

> 注意：`children:0` 时那 874/908px 是**纯空白**（还没注入骨架）；`children:2`（回退后）则是带着 8 个 tab 的工作台骨架浮在研报页底下。

## 4. 新 P0-B · 工作台不贴顶，顶部残留 180px 旧 UI

回归探针列出 `?view=workbench` 下 **body 仍可见的直接子元素**：

| 元素 | 高 | top | display |
|---|---|---|---|
| `.top-sticky` | 107 | 0 | block |
| `footer.foot.muted` | 73 | 107 | block |
| `label.ls-switch` | 35 | 825 | flex |
| `#toTop` | 34 | 822 | block |
| `#drawerMask` | 874 | 0 | block |
| `#drawer` | 874 | 0 | flex |
| `#sRoot` | 874 | **180** | flex |

- 107 + 73 = **180**，正好是 `sRoot.rectTop:180`；`bodyScrollHeight 1054 > innerHeight 874` → 工作台视图产生 180px 无谓滚动，且顶部压着旧顶栏和旧页脚。
- `#drawer` / `#drawerMask` 虽 `aria-hidden="true"`，但仍以全屏 `display` 存在（靠 transform 离屏），有遮挡工作台浮层的风险；`ls-switch` / `toTop` 会浮在工作台底部。
- **这条我 08 册的补丁也有责任**：P0-1 只点了 `main` + `preMainPanels`，文字里虽提过「`#drawer` 需一并收起」但没写进代码，落地照抄就漏了。修「隐藏研报整页」不能只盯 `<main>`，得按 body 直接子元素逐个过一遍。

## 5. 补丁（两处 CSS，零 DOM 搬迁，零视觉风险）

### 5.1 修 P0-A

```css
/* s-components.css —— 紧跟 .s-app 定义（L29 之后） */
.s-app[hidden] { display: none; }
```

选择器权重 (0,2,0) > `.s-app` (0,1,0)，作用域最小：不动全局 `[hidden]`、不影响 `#sRoot` 激活态（`hidden=false` 时不命中）、不影响其他 `.s-app` 使用场景。

> 不建议写 `[hidden]{display:none!important}` 全局规则——`style.css` 里有大量 `.xxx[hidden]{display:none}` 与 `!important` 的既有约定，全局改动会牵动研报视图的十几处面板。

### 5.2 修 P0-B

```css
/* style.css —— 追加到 P0-1 视图规则（L2077）之后 */
body[data-view="workbench"] > .top-sticky,
body[data-view="workbench"] > footer,
body[data-view="workbench"] > .ls-switch,
body[data-view="workbench"] > #toTop,
body[data-view="workbench"] > #drawer,
body[data-view="workbench"] > #drawerMask { display: none; }
```

这些都经探针确认是 `document.body.children` 直接子元素，`>` 成立；且带 `body[data-view="workbench"]` 前缀，**默认/终端视图完全不受影响**。若后续发现 `#drawer` 被移进容器，把对应行的 `>` 改成后代即可。

### 5.3 可选加固（`s-root.js`）

`route()` 里同步给这些元素设 `hidden` 做双保险也可以，但 CSS 更集中、更易审计；建议**只改 CSS**，避免再引入一次「属性被作者样式覆盖」的同型问题。

## 7. 附注：部署与缓存（非阻断，但值得知道）
