| # | 定性 | BRIEF 依据 | 证据数值 |

## 1. 三层信息架构

### 1.1 三层完整定义

| 层 | 回答的问题 | 内容判据（满足任一即入层） | 主视图中的形态 | 默认展示规则 | 目标权重 |
|---|---|---|---|---|---|
| **结论层** | 「今天盘面有什么风险 / 我该执行什么仓位」 | ① 单一数值或单一判断即可回答风险；② 带风险等级 / 待命 / 空仓等业务状态；③ 是「筛选后」的结果而非原始记录 | 结论指标条、风险摘要条、概览结论卡、研报摘要卡、主线标的结论 | **常驻、不可折叠、不进抽屉**，全部落在 0–184px（移动 0–296px） | **40%**（现行 17%） |
| **证据层** | 「为什么得出这个结论」 | ① 走势 / 分布 / 因子 / 明细等解释性图形与数据；② 需要下钻才能读完的多行数据；③ 背景市场与口径说明 | 60 日情绪分走势、七因子环形仪表、regime 分布、主线题材、ETF 对冲卡、个股明细、外围、因子健康度、研报摘要出口 | 首屏给出**缩略卡 + 「查看明细」**，完整数据进证据 tab 或抽屉 D1/D2；长文移出主视图 | **42%**（现行约 25%） |
| **操作层** | 「我要执行 / 审计什么」 | ① 产生写操作（委托、参数、写盘）；② 审计流水与数百行明细；③ 导出 / 打印 / 系统参数 | 模拟盘、回测、"系统设置"、打印导出口 | **默认折叠 / 默认摘要态**，明细一律进抽屉 D3 或虚拟列表，**不占文档流高度** | **≤18%**（现行 58%） |

**分层判据补充**：同一 DOM 块跨层时按「结论上提、证据下沉、操作收编」拆分，不以原 DOM 归属为准。例如 `zone-overview`（1147px）内的 `38.4` 与 6 项指标上提到结论层，60 日走势图与七因子仪表留在证据层，`aiReportCard` 的 352px 全文压成 220px 摘要卡。

### 3.3 首屏线框要点（给视觉 / 前端的可编码约定）

```
┌─ 顶栏 64px（≥1024）/ 56px（<1024）───────────────────────────────┐
│ 已收盘 · 数据日 · regime 90日 · [20][30][60][90] · 当前regime  ⋯ │

├─ 风险摘要条 48px（收起态）────────────────────────────────────────┤

```

- 结论指标条每格：`min-width:0`、`white-space:nowrap`、数字用等宽数字（`font-variant-numeric: tabular-nums`），避免折行裁切。
- 结论指标条不使用 `overflow-y:auto`，不锁 `height/min/max:3rem`；容器高度由内容 + padding 决定，骨架与真实内容 1:1（文件 03 第 4 节）。
- 辉光只允许三处：选中细边光、警报呼吸、主图当前值微光点；其余一律无辉光。
- 字级：结论数值 D0 40px → 卡标题 H3 14px → 口径 Caption 12px，三层落差解决 BRIEF 3.5「字号几乎一档」。

### 5.3 返回路径与浏览器后退语义

- 抽屉：`Esc` / 遮罩 / 关闭按钮 / 移动下滑 → 回到触发行（不写 history，或用 `history.state` 轻量记录，关闭时清理参数）。
- 长文专用页：写一条 history，浏览器后退 → 主视图来源 tab + 原滚动位置（用 `sessionStorage` 存 tab 名与 `scrollY`）。
- 打印 / 导出：不写 history，关闭即回来源容器。
- 跨视图联动下钻：先 `pop` 覆盖层再 `push` 目标 tab，保证后退一次回到下钻前的状态。
