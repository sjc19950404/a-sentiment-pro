# 销案 #03-03

## 结论
03-03 的「油气开采及服务 12.22% vs 大盘 -3.07%」告警，复核后判断为**非脏数据**，属于**事件驱动型逆市异动**，予以销案。

## 证据
- 2026-10-08 A股休市后首个交易日，油气开采及服务板块逆市走强，多只成分股拉升，板块指数涨幅约 2%—3%，与「逆市上涨」方向一致（来源：网易 / 搜狐 / 九方智投 10-08 盘中与收盘报道）。
- 驱动原因可交叉验证：当日国际油价直线拉升，WTI 原油涨约 3%—4%，布伦特原油涨超 3%，国内原油主力合约涨约 8.96%；消息面为中东冲突升级，包括沙特利雅得传出爆炸声、也门胡塞武装袭击机场、美国被曝准备对伊朗重启军事行动等（来源：九方智投 / 搜狐 / 网易 10-08）。
- 该异动并非孤立脏值：10-08 板块主力资金净流入约 1.22 亿元，10-09 板块收跌 0.06% 后回归常态，10-12 板块再度回落约 7.19%，说明 10-08 的冲高属于短线事件脉冲，而非数据异常（来源：东方财富板块异动与资金流）。

## 复核原因
「油气开采及服务 12.22%」与大盘 -3.07% 反向，表面看像脏数据；但结合 10-08 国际油价飙升、中东地缘冲突升级、板块资金净流入及多只成分股同步拉升，可确认该异常为事件驱动型主题轮动。若 12.22% 为当日板块指数涨幅，则高于主流报道中的约 2%—3%，需再核对数据口径；若为板块内个股涨幅或成分加权口径，则与当日行情一致，无需修正。
