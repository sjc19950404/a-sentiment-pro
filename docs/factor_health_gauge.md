# 因子健康度仪表（Factor Health Gauge）· 口径归档

> 2026-11-09 外部拍板并落地。本文是口径唯一权威归档——阈值改动须同步本文与判定引擎注释。

## 1. 解决什么问题

回答「因子会衰退吗」的**持续监控**。此前该分析只能临时手跑、无人主动复检；因子衰退有三类，
仪表对三类分别布防：

| 衰退类型 | 机制 | 防线 |
|---|---|---|
| 实现漂移（代码/数据变了导致策略行为变） | 代码假象 | 双轨锚点门禁（已有，非本仪表） |
| 统计性衰退（样本外表现衰减） | alpha 变薄 | **本仪表 ①~④ 针** |
| 结构性失效（制度/生态突变） | 跳变式失效，历史回测不可见 | **本仪表 ⑤ 针（生态哨兵）** |

## 2. 三态预警（主判定）

| 状态 | 条件（任一） |
|---|---|
| ✅ 健康 | 最新周超额 ≥0 且 8 周超额胜率 ≥52% 且 无连续负超额 |
| ⚠️ 观察 | 8 周胜率 48%~52% / 单周超额转负 / 4 周均值 alpha 低于全史 30 分位（走平转弱）/ 周分歧率 ≥P90 |
| ❌ 告警 | 连续 ≥2 周负超额 / 8 周胜率 <48% / 4 周均值 alpha 低于全史 30 分位且为负（拐头向下）/<br>【席位因子失效预警】席位增量 alpha 连续 ≥2 周 ≤ -5pp（provisional，人工复标后更新）/<br>【博弈生态异动预警】周分歧率 ≥P95 或 ≥3×前 4 周中位（且 ≥P90） |
| ⏳ 积累中 | 历史 <8 周（只报数据不判定） |

## 3. 五根指针

| # | 指针 | 口径 | 是否告警 |
|---|---|---|---|
| ① | 周度 Alpha 序列 | 策略周收益 − 基准周收益。策略 = V5.2 生产参数（train）全档重放、等权两资产池、含换手成本（与 paper_dual_track A 轨同代码路径）；基准 = 两资产等权买入持有（不择时对照） | 是（主判定） |
| ② | Alpha 胜率 | 最近 8 周 alpha>0 占比。健康线 52% / 告警线 48% | 是（主判定） |
| ③ | 原始滚动夏普 | 最近 8 周策略日收益年化夏普（周 ×√52） | **否（仅展示）** |
| ④ | 席位因子增量 Alpha | 对照变体回算：候选 = 当日涨停 ∩ 席位明细；组 G = filterOne 默认（准入 ③④ 全开）、组 B = `skipSeatRules`（只关席位规则，主板限制保留）；表现 = T+1 续板率（次日仍在涨停名单）——**单票行情不可得的代理口径**，度量信息含量而非真实收益；增量 = rate(G) − rate(B)，周级池聚合（池 ≥3 票的日才计入） | 是（连续 2 周 ≤ -5pp 告警） |
| ⑤ | 周度分歧频率 | 结构尺（⑧a 规则，退化版）与情绪尺分歧日占比：偏热 = 涨停≥60 或（封板率≥75% 且炸板≤10）；偏冷 = 涨停≤25；分歧日 = (ice/ebb & 偏热) \| ((climax/shift) & 偏冷)。晋级失败率历史 0 覆盖 → 该分支如实跳过 | 是（≥P95 或 ≥3×中位告警） |

历史分位动态阈值：③④⑤ 的分位均从自身历史序列计算（④⑤需 ≥12 周）。

## 4. 分 Regime 基准校验（披露，不参与判定）

按周主导 regime 分组统计平均 alpha 与胜率。语义：
- ice/ebb 组 alpha 为正 = 避险价值在工作（策略该赢的地方赢）；
- climax/recover 组 alpha 接近 0 = 跟涨不落后；
- climax 组显著为负 = 换手成本拖累（首期数据：-0.53%/周、胜率 25%，留观）——**若持续为负且放大，是"策略在高潮期应降低换手"的人工资讯**，不是自动调参信号。

## 5. 纪律（写死在代码，不可由仪表自动触发任何变更）

1. **系统禁止自动修改规则**——仪表只读 + 落盘账本，绝不写 config/params/回测参数。
2. **重大调整由人工评估后上线**——告警仅供人工决策；阈值改动须同步本文与引擎注释并经人工评审。
3. **永久保留独立风控兜底闸口**——pi_run 各 gate、双轨锚点门禁、EOD 守卫链独立于本仪表，仪表非风控替代。
4. provisional 阈值（席位 -5pp）在样本充足后人工复标；分歧 P90/P95 随历史自滚动。

## 6. 数据与运行

- 引擎（纯函数）：`src/factor_health.js`（judge / regimeBreakdown / weekKey）。阈值常量：ALARM_WIN 0.48 / HEALTHY_WIN 0.52 / MA4_PCT 0.30 / MIN_WEEKS 8 / SEAT_ALARM -0.05。
- 脚本：`scripts/factor_health.mjs`（EOD 挂载于 pi_run.sh，push_eod 之前；每日跑、自然周聚合、周一为周起点、幂等同周覆盖、fail-open 不拦链）。
- 账本：`data/factor_health_history.json`（快照 + 全史周序列：alpha / seatAlpha / divergRate / regime / exposure）。
- 席位对照：`src/seat_factor_alpha.js`（对照变体回算，`skipSeatRules` 仅供此用途，见 lhbfilter.js JSDoc 警告）。
- 展示：主视图「回测回测·V5.2」区尾部「因子健康度仪表」卡（5 针 + 状态灯 + 折叠明细）；周报 `payload.factor_health` 段（build_ai_report 注入账本）。
- 测试：`test/factor_health.test.mjs`（三态边界 + 两条新告警 + 优先级 + weekKey 跨周）。

## 7. 首期判读（2026-11-09，56 周）

- 判定：⚠️ 观察（最新周超额 -2.53%：策略 -0.27% vs 基准 +2.25% 反弹周，ice 盖帽 38% 仓位未吃满——避险纪律的正常代价）。8 周胜率 75%。
- 分 regime：冰点 24 周 +0.28%/周（胜率 54%）、退潮 9 周 +0.13%（56%）——避险价值实证；高潮 12 周 -0.53%（25%）——换手成本拖累，留观。
- 席位增量：全史均值 +1.1pp、55 周中 53% 为正——轻微正贡献，未现失效。
- 分歧频率：全史分歧日 18.8%；历史告警触发 5 周（2026-05~06 集中）——哨兵自标定合理。
- 背景归因（2026-11-09）：滚动样本外夏普近期下滑是市场 beta（基准 -1.41%/段）而非因子衰退——alpha +0.36%/段、胜率 57%。
