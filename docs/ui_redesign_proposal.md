## 1. 一句话结论

**最大的问题不是「不好看」，是「有两套」。** 云端与本地各自维护了一套颜色 token，
同一语义三个值全不一样（涨红 `#f0616d` ↔ `#ff5a5a`、跌绿 `#3fb950` ↔ `#2fbf8f`、
正文 `#e6edf3` ↔ `#d7dee9`）——它们已经漂移。在此基础上才是排版与美化的具体问题。

## 3. 设计系统提案（若走「统一」路线）

### 3.1 颜色（**双端统一为一套**，值以云端现行 `--up/--down` 为准）

```
--bg      #0d1117   背景
--card    #161b22   卡片
--card2   #1b232c   卡片次级
--line    #21262d   分隔线
--txt     #e6edf3   正文      ← 本地版 #d7dee9 收敛到此
--muted   #8b949e   辅助      ← 本地版 --dim/#8a94a6 收敛到此
--up      #f0616d   涨(红)    ← 本地版 #ff5a5a 收敛到此
--down    #3fb950   跌(绿)    ← 本地版 #2fbf8f 收敛到此
--acc     #58a6ff   强调      ← 本地版 --accent 收敛到此
--warn    #d29922   警示      ← 本地版 --gold 收敛到此
--focus   #58a6ff   焦点环
```

**新增**（现在缺的语义色，建议登记）：`--ok` / `--info` / `--panel`（补 #1 的洞）。

### 3.2 间距 scale（现在随意值全部收敛到这 6 档）

`4 / 8 / 12 / 16 / 24 / 32`

### 3.3 字号 scale（砍掉 6 个半档，正文从 12.5 提到 13–14）

```
12   辅助说明
13   正文
14   卡片标题      ← 修 #7 层级倒挂
16   分区标题
20   关键数值
24   大数字(情绪分)
```

### 3.4 圆角 / 阴影

- 圆角 3 档：`--r-sm 4` / `--r-md 8` / `--r-lg 12`（特殊形如 pill 用 99px 单列）
- 阴影 2 档：`--sh-1`（卡片）/ `--sh-2`（浮层抽屉）

### 3.5 状态样式补齐

- **加载态**：新增 `.skeleton`（骨架屏）或 `.spinner`，至少给主面板一个
- **空态**：统一为一个 `.empty` 组件（内距 16px、文案 13px `--muted`）
- **disabled**：统一 `opacity:.5` + `cursor:not-allowed`
- **焦点**：删掉 6 处 `outline:none`，或改为 `outline:none` + 自定义 `--focus` 指示

## 4. 落地路径（**三选一，请你拍板**）

### 方案 A · 最小修复（约半天，只修 P0）

只做：补 `--panel` 定义（#1）、修 6 处焦点（#2）、加一个通用加载态（#4）。
**不动**双端差异、不动 token 体系。

- 优点：风险极低，不改任何视觉
- 缺点：**双端漂移（#3）仍在**，两套界面颜色继续各走各的

### 方案 B · token 化 + 双端收口（推荐，约 2–3 天）

1. 建一套统一 token（§3），云端 `style.css` 全量替换硬编码
2. 本地版 `ui/template.html` 内联样式改为**引用同一套 token**（同源方式见下）
3. 补齐加载/空/焦点/disabled 状态组件
4. 间距与字号收敛到 scale

**关键决策：本地版如何与云端共享 token？**
零构建约束下有三个做法，影响后续维护方式，需要你选：

| 做法 | 说明 | 代价 |
|---|---|---|
| B1 本地版外链 `style.css` | 删掉 `ui/template.html` 内联样式，`<link href="../style.css">` | 单文件自包含性丢失（离线分发时 css 要一起带） |
| B2 构建时注入 | `scripts/build_ui.mjs` 在生成 dist 时把 token 块内联进去 | 多一步构建，但保留单文件 |
| B3 两边各写一份但**值同源** | token 值写进 `config/` 或 `schemas/`，两边生成 | 需新增生成脚本，最不推荐（易再漂移） |

### 方案 C · 全面改版（不建议现在做）

重新设计视觉语言（布局、配色、信息架构）。工作量大，且与「数据纪律优先」的当前阶段不匹配。
